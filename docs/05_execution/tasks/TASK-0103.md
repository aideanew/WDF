## 归属切片
S1（AT-0103）

## 来源需求
03 契约 §0 缺口 G-06（`event.result` 无请求类型）、G-07（`social.send/pull` 无出参类型）

## 来源方案
`docs/04_planning/plan-v001/03-contracts-freeze.md` §3.4.1 动作表

## 目标
补齐缺失的出/入参类型，使前端可以只凭 `packages/contracts` 写出可编译的调用代码。

## 输入
- `packages/contracts/src/event/index.ts`、`social/index.ts`
- `packages/contracts/src/common/actions.ts`（动作目录，不得增删动作）
- 03-contracts-freeze.md 的动作表

## 输出路径
- `packages/contracts/src/event/index.ts`
- `packages/contracts/src/social/index.ts`

## 执行步骤
1. 在 `event/index.ts` 增加 `export interface EventResultReq { sessionId?: string }`（缺省取最近一场）。
2. 在 `social/index.ts` 增加 `export interface SendRes { ok: boolean }` 与 `export interface PullRes`（已有则不动）。
3. **不得**新增/删除/重命名任何动作；**不得**改动 `common/errors.ts`（错误码补缺是独立 AT）。
4. 运行 `npm run gen` 让 `api-catalog.md` 与客户端同步包更新（生成物由脚本产出，不手改）。

## 验收标准
1. 新增类型可被 `import * as event from '@wdf/contracts'` 使用；
2. `ACTIONS` 仍是 20 条（数量不变）；
3. `npm run verify` 通过。

## 验证命令
```powershell
npm run verify
node -e "const a=require('./packages/contracts/dist/common/actions.js');console.log(Object.keys(a.ACTIONS).length)"
```
（未构建 dist 时以 `npm run guard` 的类型检查结果为准）
