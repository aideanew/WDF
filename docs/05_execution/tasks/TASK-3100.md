## 归属
- 所属切片：S-PLAY（前置：无配置读取则背包/合成页无法显示任何真实名称与价格）
- 来源需求：MUST-07（数值来自 game-data，不得写死）
- 来源方案：`tools/gen/config.mjs:80` 已把每张表写到 `client/assets/resources/config/<table>.json`（实测 `recipes.json` 为数组，元素含 `id/output/output_count/inputs/station`，空字段被省略）

## 目标
提供**唯一**的客户端读表入口：同步读缓存、异步预加载、幂等、失败不抛异常；`_manifest.json` 的 `configVersion` 可读。

## 输入
- 产物：`client/assets/resources/config/{items,recipes,prices,_manifest}.json`（`npm run gen` 生成）
- 契约：`packages/game-core/src/generated/config-types.ts`（`ItemsRow/RecipesRow/PricesRow`）
- 前置状态：`services/config/index.ts` 当前仅 2 行（`export const SERVICE='config'`），**无任何实现**

## 输出
- `client/assets/scripts/services/config/index.ts`（实现：`table/preload/configVersion/clearCache`）
- `client/assets/scripts/services/config/tables.ts`（新：表名联合类型 + 行类型映射，**不 import cc**，供纯函数与测试复用）

## Execution Steps
1. [ ] `tables.ts` 定义 `export type TableName = 'items' | 'recipes' | 'prices' | 'locks' | 'chests'`，以及 `export interface TableRowMap { items: ItemsRow; recipes: RecipesRow; ... }`（行类型直接从 `generated/game-core/generated/config-types` 取，**不复制字段**）
2. [ ] `table(name)`：同步返回缓存数组；未加载返回 `[]` 并 `console.warn('[config] 未预加载: '+name)`；**返回只读视图**（不得让调用方改到缓存，用浅拷贝数组）
3. [ ] `preload(names)`：`resources.load('config/'+name, JsonAsset)` 并行加载；已加载的跳过（幂等）；返回 `{ loaded: string[]; failed: string[] }`；失败只 warn 不抛
4. [ ] `configVersion()`：读 `resources/config/_manifest.json` 的 `configVersion`；**不得**回落到硬编码字面量
5. [ ] `clearCache()`：测试与热更用，清空缓存与在途 promise（避免并发重复加载）
6. [ ] 预加载去重：同一表并发 `preload` 只发一次 `resources.load`（用 `Map<string, Promise>`）

## 验收标准
- [ ] 未预加载时 `table('items')` 返回 `[]` 且不抛异常（有 warn）
- [ ] `preload(['items','recipes'])` 后 `table('items').length === 106`、`table('recipes').length === 80`（数值来自生成物，实测行数）
- [ ] 连续两次 `preload(['items'])`（并发 `Promise.all`）→ `resources.load` 实际只触发一次（用日志或 stub 计数证明）
- [ ] `configVersion()` 返回 `_manifest.json` 的真实值（与 `generated/game-core/generated/config-types.ts` 的 `CONFIG_VERSION` 相同；若不同即为数值未同步，必须报错而不是静默）
- [ ] 调用方修改返回值不影响下一次读取（`table('items')[0].name='x'` 后再读仍是原名）
- [ ] `tables.ts` 不含 `from 'cc'`（守卫 `clientBoundaries` 与纯函数测试前提）
