## 归属
- 所属切片：S-CORE（纯规则）
- 来源需求：MUST-09（合成门槛）——本任务只做"材料够不够"，**不做等级门槛**（`recipes.unlock_level` 全空，见 `game-data/UNKNOWN-TABLES.md` §3）
- 来源方案：`recipes.csv` 80 行已转录（含输入/输出）

## 目标
`canCraft(recipe, inventory)` 与 `consume(recipe, inventory)` 为纯函数：同输入同输出、不修改入参、不使用 `Math.random`/`Date.now`/`cc`/IO。

## 输入
- 文档：`docs/03_solution/data/config-tables.md`
- 契约：`packages/game-core/src/generated/config-types.ts`（`RecipesRow`）
- 数据：`game-data/source/recipes.csv`（80 行，2026-10-26 实测）
- 前置状态：`packages/game-core/src/crafting/index.ts` 当前 3 行占位

## 输出
- `packages/game-core/src/crafting/index.ts`（实现）
- `tests/determinism/crafting.test.mjs`（新增）

## Execution Steps
1. [ ] 定义 `export interface RecipeShape { id: string; out: string; outCount: number; inputs: { id: string; count: number }[] }`
2. [ ] 定义 `export interface InventoryShape { [itemId: string]: number }`（只读视图，不引入存档结构）
3. [ ] `canCraft(recipe, inv): { ok: boolean; missing: { id: string; need: number; have: number }[] }` —— `missing` 按 `inputs` 顺序输出，禁止排序以免顺序不稳定
4. [ ] `consume(recipe, inv): InventoryShape` —— 返回**新对象**，不修改入参；不校验 `ok`（校验由调用方先调 `canCraft`）
5. [ ] 复用 `common/result` 的约定仅在需要错误码时使用；本函数不返回 Result（无失败码语义）

## 验收标准
- [ ] 材料恰好相等 → `ok: true`、`missing: []`
- [ ] 缺 1 个材料 → `missing` 精确含该 id，`need` 为配方值、`have` 为库存值
- [ ] 同一对象调 `consume` 两次结果相同（证明未改入参）
- [ ] 连续两次调用 `canCraft` 深比较相等（确定性）
- [ ] 源码不含 `Math.random` / `Date.now` / `from 'cc'` / IO（守卫 `gameCorePurity` 覆盖）
