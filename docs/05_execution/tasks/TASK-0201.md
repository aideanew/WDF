## 目标
在 `game-core` 里实现**纯确定性**的出钩规则：给定蓄力时长与角度，输出轨迹与命中判定，可在 Node 下测试。

## 输入
- 规则：力度条往返周期 `1200ms`（可配，来自 game-data 更好，但当前 `hooks.csv` 为空 → **先用常量并在 TASK 里标注待迁入 CSV**）
- 前置任务：S1 完成（AT-0108）

## 输出路径
- `packages/game-core/src/hook/**`（当前只有 `MODULE_ID`）

## 执行步骤
1. 定义 `HookConfig{ cycleMs, minPowerBp, maxPowerBp, armLength, flightSpeed, hitRadius }`（值从外部传入，**不写死**）。
2. 实现 `powerAt(holdMs, cfg): number`：三角波往返，`holdMs` 超过 `cycleMs` 后回落（不得无限增长）。
3. 实现 `cast(powerBp, angle, cfg): HookPath`：返回离散采样点（供表现层与判定共用）。
4. 实现 `resolveHit(path, targets, cfg): {hitIndex, dist} | null`：取首个相交目标。
5. 实现 `pullBack(hit, cfg)`：承重判定（细绳/粗绳/钢缆三档，档位值从外部传入）。
6. **硬约束**：不得 `import 'cc'`、不得 `Math.random`、不得 `Date.now`、不得 IO。

## 验收标准
1. 同输入同输出（连续 2 次调用结果深度相等）；
2. `powerAt(600)` 处于峰值区间；`powerAt(1200)` 回到起点；
3. `resolveHit` 对"轨迹穿过目标圆心"必须命中；"偏离 > hitRadius" 必须 null；
4. 承重不足时 `pullBack` 返回 `err(3101, ...)` 风格结果。
