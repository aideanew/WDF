## 来源需求
MUST-15（榜单）；已定口径（项目记忆）：「每日赶海按**装备档位**分组排名，门票固定 200 金币」——**该句的原始设计出处需在执行前复核**（见升级条件③）。

## 来源方案
`packages/contracts/src/leaderboard/index.ts`（`QueryReq.scope` 目前只有 `global|region|province`）；
`0001_init.sql` 的 `leaderboard_snapshot(season, scope, taken_at, rows)`。

## 目标
在赶海活动期间，按**装备档位**把玩家分到不同组，各自独立排名；查询只返回本组榜。

## 输入
- AT-0803 结算后的场次结果
- 装备档位定义（来自设计文档；缺失则登记未知，不编）

## 输出路径
- `server/src/modules/leaderboard/**`（分组计算与快照）
- `client/assets/scripts/features/leaderboard/view/**`（分组切换与展示）

## 执行步骤
1. **先复核分档口径**：在 v5.5 与《材料与工具总表》里找到"装备档位"的原文定义；找不到 → 停下问用户（不得自行设计档位）。
2. 快照 `scope` 复用现有字符串格式，新增形如 `event:<分档 id>` 的取值（**不改契约字段**）。
3. 查询接口按分档过滤；未带分档默认返回"全服总榜"。
4. 客户端加分档切换（2–3 个档位以内，不做无限列表）。
5. 门票 200 金币的扣费**不在本卡**（归 AT-0801 场次入口）。

## 验收标准
1. 两档玩家各自看到本档排名，互不串档；
2. 换档后 `snapshotAt` 与 `rank` 正确；
3. 分档口径在证据里能指到原文；
4. `npm run verify` 全绿。
