## 目标
把 `TASK-0201` 的规则表现为"看得懂、按得准"的出钩：力度条、钩子飞行、绳子拉伸、命中高亮。

## 输入
- 规则：`TASK-0201` 产出的 `powerAt` / `cast` / `resolveHit`
- 资源：`b-shallow`（可用色块占位，**不得**引用不存在的图集）
- 前置：S1 完成、AT-0101（工程）

## 输出路径
- `client/assets/scripts/features/hook/view/**`
- `client/assets/scripts/ui-kit/**`（如需通用力度条组件）

## 执行步骤
1. 打开 `HookView.ts`，把 `lateUpdate` 里被注释的刷新逻辑**重写**（不是简单取消注释——原逻辑未完成）。
2. 力度条：以 `powerAt(holdMs)` 驱动 UI 进度，**按真实时间**累积 `holdMs`（`dt` 累加，不用 `Date.now`）。
3. 钩子飞行：用 `cast` 的采样点做插值移动；`b-shallow` 暂无美术时用 Sprite 色块。
4. 命中：`resolveHit` 命中 → 目标缩放脉冲 + 轻微震屏（`vibrateShort` 走平台层）。
5. 回手：钩子返回时若承重不足 → 中途"脱钩"表现 + 提示（3101 文案）。
6. 性能：单帧新增节点 ≤ 10；同屏漂浮物按 `MAX_FLOATING_ON_SCREEN=20` 限制。

## 验收标准
1. 长按可以看到力度条往返（约 1.2 秒一个来回）；
2. 松手后钩子飞出并返回，全程有可视反馈；
3. 命中与未命中在画面上可区分；
4. 20 个漂浮物同时存在时无明显掉帧（记录帧率，标"尚无基线"直到真机测）。
