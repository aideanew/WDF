## 归属切片
S0（AT-0101 + AT-0102）

## 来源需求
MUST-17（包体与 Bundle 划分）、01 事实基线 C11（`.meta/.scene/.prefab` 全为 0）

## 来源方案
`docs/03_solution/architecture/bundle-plan.md`、ADR-0006（脚本全在主包，Bundle 只装资源）

## 目标
让 `client/` 成为一个真正能被 Cocos Creator 3.8 打开、预览、构建的工程，并预置 7 个 Asset Bundle。

## 输入
- 文档：`bundle-plan.md`、ADR-0006、`docs/04_planning/plan-v001/12-first-cut.md` §12.3
- 软件：Cocos Creator 3.8.x（LTS）
- 前置状态：无（这是整条链的起点）

## 输出路径
- `client/settings/**`（编辑器生成，**不得手改**）
- `client/assets/**/*.meta`（编辑器生成，**不得手改**）
- `client/assets/scenes/Boot.scene`
- `client/assets/bundles/{b-common,b-shallow,b-deep,b-island,b-defense,b-event,b-social}/`

## 执行步骤（【人工】，大白话）
1. 打开 Cocos Dashboard → **新建项目** → 模板 **Empty** → 路径 `e:\Demo\WDF\client` → **创建**。
2. 进编辑器后 **项目设置 → 项目数据** → 设计分辨率 `720 × 1280`，适配 `Fit Height`。
3. 资源管理器右键 `assets` → **新建 → 文件夹** `scenes`；右键 `scenes` → **新建 → 场景** → 命名 `Boot` → `Ctrl+S` 保存。
4. `assets` 下建 `bundles`（若无），在 `bundles` 内建 7 个文件夹：`b-common`、`b-shallow`、`b-deep`、`b-island`、`b-defense`、`b-event`、`b-social`。
5. **逐个选中** 每个 `b-` 文件夹 → 右侧检查器勾选 **"配置为 Bundle"** → Bundle 名与文件夹同名（**禁止** `main`/`resources`/`internal`/`start-scene`）。
6. **项目 → 构建发布** → 平台 **微信小游戏** → 起始场景拖入 `Boot` → 关闭（暂不构建）。

## 验收标准
1. 编辑器能打开工程、能预览 `Boot` 空白场景；
2. `.meta` 文件数 > 0；
3. 7 个 Bundle 在检查器里都显示已配置；
4. `client/settings/` 下出现 `project.json`。

## 验证命令
```powershell
(Get-ChildItem -Recurse e:\Demo\WDF\client -Filter *.meta).Count      # 期望 > 0
Test-Path e:\Demo\WDF\client\settings\project.json                    # 期望 True
(Get-ChildItem e:\Demo\WDF\client\assets\bundles -Directory).Name     # 期望 7 个 b- 目录
```
