## 归属切片

## 来源需求
MUST-08（鉴权）、MUST-07（幂等）、03 §3.4.3 Identity

## 来源方案
`contracts/account`（LoginReq/LoginRes）、`identity`/`player` 表、03 §3.4.3 令牌 claims 建议

## 目标
让 `account.login` 真正签发会话，并让所有 `auth=true` 的动作在缺 token 时返回 `2001`。

## 输入
- 契约：`packages/contracts/src/account/index.ts`
- 表：`server/db/migrations/0001_init.sql` 的 `player`、`identity`、`idempotency`
- 前置任务：AT-0103（类型补齐）；前置状态：本地 PostgreSQL 已执行 `0001_init.sql`

## 输出路径
- `server/src/gateway/auth.ts`（新建）
- `server/src/modules/account/**`（实现 `handlers` 中对应项）
- `server/src/gateway/rpc.ts`（接入鉴权中间件，不改变现有分发语义）

## 执行步骤
1. 建 `auth.ts`：`signToken(claims)` / `verifyToken(token)`；claims 采用 03 §3.4.3 建议结构 `{sub,region,plat,admin?,iat,exp,jti}`；**`admin` 只能由服务端签发，不得来自请求体**。
2. 实现 `account.login`：按 `plat + code` 查/建 `identity` → 查/建 `player` → 返回 `LoginRes`（`isNew`、`serverTime`、`region`）；`anonymousSaveId` 存在时把本地进度认领到该 player（可先只记录映射）。
3. 在 `rpc.ts` 分发前插入鉴权：`ACTIONS[a].auth === true` → 校验 token；无效/缺失 → `NOT_LOGGED_IN 2001`；过期 → `SESSION_EXPIRED 2002`。
4. 幂等：`idempotent` 动作强制 `rid`；同一 `(playerId, rid)` 命中 `idempotency` 时回放首次响应。
5. **不得**实现其它 15 个动作（各自由对应 AT 负责）。

## 验收标准
1. 合法登录返回 `c=0` 且 `d.token` 非空；
2. 无 token 调 `save.pull` 返回 `c=2001`；
3. 过期 token 返回 `c=2002`；
4. 同一 `rid` 调 `save.push` 两次，`save_snapshot.revision` 只 +1（该 AT 需 AT-0107 配合，届时联测）。

## 完成情况（2026-10-23）

**已交付**：
- `server/src/gateway/auth.ts`：HMAC-SHA256 自签令牌，`{sub,region,plat,iat,exp,jti,admin}`；`admin` 只由服务端签发（`issueToken` 里强制 `admin:false`，不读请求体）
- `server/src/gateway/rpc.ts`：动作校验 → **版本闸** → payload 校验 → 鉴权 → 幂等 → 分发
- `server/src/gateway/payload.ts`：zod 分批校验（本批覆盖 4 个动作，其余暂不校验以免大范围回归）
- `server/src/gateway/idempotency.ts`：只缓存 `c===0` 的响应，失败允许同 rid 重试
- `server/src/modules/account/{repo,service,handlers}.ts`：本地登录用 `sha256(plat:code)` 派生稳定伪 openid，重启不换号；`WDF_AUTH_MODE=platform` 时明确抛错（真机阶段再接 code2session）
