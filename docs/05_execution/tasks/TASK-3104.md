## Execution Steps
1. [ ] `LeaderboardModel.fetch(scope='global', cursor?)`：调 `RpcClient.invoke('leaderboard.query', {scope, limit:20})`
2. [ ] 态映射：`c===0` 且 `items.length>0` → `success`（`items` 为 `QueryRes.items`，**非 `rows`**，BASE-21）；`c===0` 且空 → `empty`；其它 → `toUxState(c)`
3. [ ] 渲染：名次 / 名称（服务端兜底 `玩家<后4位>`）/ 收益；当前玩家行高亮（按 playerId 匹配）
4. [ ] 空态文案："本季还没有人上榜，先去打捞" + 刷新按钮
5. [ ] `4001` 态显示"操作过于频繁"并禁用刷新 3s（对应 DESIGN-0001 §2 的退避规则）
6. [ ] 下拉/按钮刷新时保留旧榜 + 顶部细进度条（DESIGN-0001 §4 规则 1）
