## Execution Steps
1. [ ] 复用 `to-client.mjs` 的 targets 映射（`packages/game-core/src`→`game-core`、`packages/contracts/src`→`contracts`），**不要复制粘贴路径常量**：抽出共享常量或直接 import
2. [ ] 对每个源 `.ts`：读源内容 → 前置 `GEN_HEADER` → 与目标文件内容**规范化比较**（统一换行、去尾随空白），不使用 `_sync-manifest.json` 的哈希（那是"未手改"检查，不是"已同步"检查）

>

>    时 `git checkout` 把源文件还原成 CRLF → **守卫假红且 `git status` 显示干净**（已复现）。
> 2. 抽 `tools/lib/sync-targets.mjs` 共享 `SYNC_TARGETS`（本卡步骤 1 的要求，**这部分照做了**）。

> 实际改动：新增 `tools/lib/sync-targets.mjs`、`.gitattributes`（仅 packages/tools/server → `eol=lf`，
> 135 个既存 CRLF 文件 churn=0）；修改 `tools/sync/to-client.mjs`、`tools/guard/checks.mjs`
> （`norm()` 规范化 + 换行差异单独成条报错）。
