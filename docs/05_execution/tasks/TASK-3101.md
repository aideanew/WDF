## 归属
- 所属切片：S-PLAY（可玩闭环的第 1 刀）
- 来源需求：MUST-01（打捞主路径可进入）、UI-0002（界面清单）
- 来源方案：`features/hook/view/HookView.ts`（纯代码建 UI + Graphics 的既有范式，227 行，已验证可用）

## 目标
从启动页进入后出现主界面，四个 Tab（打捞 / 背包 / 合成 / 榜单）+ 设置入口可来回切换，每个面板先给统一空态占位，不报错、不白屏。

## 输入
- 文档：`docs/03_solution/design/DESIGN-0001-ux-states.md` §4（态规则）、`docs/03_solution/ui/screen-inventory.md`
- 契约：`common/ux.ts`（TASK-3001 产出）
- 前置任务：TASK-3001（UX 类型）
- 前置状态：`BootController` 已能建 UI；`features/hook` 已可跑

## 输出
- `client/assets/scripts/app/MainView.ts`（新增：Tab 容器 + 切换）
- `client/assets/scripts/app/BootController.ts`（改为：进入主界面）
- `client/assets/scripts/features/inventory/view/InventoryPanel.ts`（新增：桩）
- `client/assets/scripts/features/crafting/view/CraftingPanel.ts`（新增：桩）
- `client/assets/scripts/features/leaderboard/view/LeaderboardPanel.ts`（新增：桩）
- `client/assets/scripts/features/settings/view/SettingsPanel.ts`（新增：桩）

## Execution Steps
1. [ ] `MainView` 用 `Graphics` 画底栏 4 个 Tab（固定尺寸，按 `view.getVisibleSize()` 计算），子节点 Label 显示名称
2. [ ] Tab 切换：只 `active` 对应面板节点，不销毁重建（避免重复请求）
3. [ ] 四个 Panel 桩：各自渲染一个标题 + 统一 `empty` 文案（文案取自 DESIGN-0001 §4 的"空态必须给下一步"）
4. [ ] `BootController` 成功路径末尾改为挂载 `MainView`
5. [ ] 打捞 Tab 内嵌现有 `HookView`（不改其内部逻辑）
6. [ ] 每个 Panel 暴露 `refresh(): void` 空实现，供后续任务覆写
