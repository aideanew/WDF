## 归属
- 所属切片：S-CORE
- 来源需求：MUST-07（`items` 106 行已转录）、MUST-08（重量字段全空 → 本任务**不碰重量**）
- 来源方案：`docs/03_solution/ui/screen-inventory.md`（背包界面）

## 目标
把存档里的 `modules.inventory`（扁平 map：`{ [itemId]: number }`，**注意没有 `.items` 子键**）投影成可展示行：已知 id 补 `name/category/base_price`，未知 id 单独返回而不崩溃。

## 输入
- 契约：`packages/game-core/src/generated/config-types.ts` → `ItemsRow`
- 存档结构：`packages/game-core/src/save/schema.ts`（`modules: Record<string, unknown>`）
- 前置状态：`inventory/index.ts` 当前 3 行占位

## 输出
- `packages/game-core/src/inventory/index.ts`（实现）
- `tests/determinism/inventory.test.mjs`（新增）

## Execution Steps
1. [ ] 定义 `export interface ItemRow { id: string; name: string; category: ItemsRow['category']; basePrice: number; count: number }`
2. [ ] `listRows(section: unknown, items: Record<string, ItemsRow>): { known: ItemRow[]; unknownIds: string[] }`
3. [ ] `section` 允许为 `undefined` / 非对象 → 返回 `{ known: [], unknownIds: [] }`（不抛异常，存档可能来自旧版本）
4. [ ] 数量 ≤ 0 的条目跳过（不展示 0 个）
5. [ ] 输出顺序：按 `basePrice` 降序，价格相同按 `id` 升序（**确定性排序**，不依赖对象键顺序）
6. [ ] 显式不读取 `weight/capacity/stack/unlock_level`（全空，读 0 会显示假数据）

## 验收标准
- [ ] 3 个已知 + 1 个未知 id → `known.length === 3`、`unknownIds === ['xxx']`
- [ ] `listRows(undefined, {})` → 空结果且不抛
- [ ] 数量 0 的条目不出现在 `known`
- [ ] 相同输入两次调用结果深比较相等
- [ ] 源码无 `Math.random`/`Date.now`/IO
