## 归属
- 所属切片：S-PLAY
- 来源需求：MUST-07（`items` 106 行已转录）、MUST-08（重量全空 → **不显示重量**）
- 来源方案：`TASK-3202` 的 `listRows`

## 目标
背包 Tab 列出存档中已有物品（名称 / 类别 / 基准价 / 数量），空存档显示空态；未知 id 不导致崩溃。

## 输入
- 契约：`packages/game-core/src/inventory` 的 `ItemRow/listRows`（TASK-3202 产出）
- 数据：`client/assets/scripts/generated/game-core/generated/config-types.ts`（`ItemsRow`）
- 前置任务：TASK-3101（面板桩）、TASK-3202（投影函数）
- 前置状态：`LocalSave.load()` 可用；`HookModel.applyToSave` 会写 `modules.inventory.items`

## 输出
- `client/assets/scripts/features/inventory/model/InventoryModel.ts`（实现，当前 6 行占位）
- `client/assets/scripts/features/inventory/view/InventoryPanel.ts`（实现 TASK-3101 的桩）

## Execution Steps
1. [ ] `InventoryModel.load()`：`LocalSave.load()` → 取 `modules.inventory` → 调 `listRows`
2. [ ] `state`：`{ kind: 'loading' } | { kind: 'empty' } | { kind: 'success'; rows: ItemRow[] } | { kind: 'error'; ux: UxView }`（态由 TASK-3001 的 `toUxState` 决定）
3. [ ] Panel 渲染：每行 `名称 ×数量 | 类别 | 基准价`，最多 20 行 + 滚动/分页占位
4. [ ] 空态文案："还没有捞到东西，去打捞吧"+ 一个跳转 Tab 的按钮
5. [ ] 埋点：进入空态上报 `ui.empty{action:'inventory'}`（走 `features/telemetry`，失败不上屏）
6. [ ] **不显示重量/容量**（`weight/capacity` 全空，显示 0 属伪造数据）

## 验收标准
- [ ] 存档中放入 `item_0001×3`、`item_0002×1`、`bad_id×1` → 列表出现 2 行、无崩溃、日志记 1 条 unknown
- [ ] 空存档 → 空态文案 + 按钮，不是空白页
- [ ] 任意行显示的名称/价格与 `items.csv` 对应行一致（人工抽 3 项核对）
- [ ] 界面不出现"重量"字样
- [ ] 客户端类型检查通过；守卫 9/9
