# 《我的筏不可能这么大》深度设计方案 v5

> 一句话：**一根绳钩，长按蓄力、松手出钩，把一块破木筏捞成一座海上城。**
> 平台：微信 / 抖音小程序先行，后续 APP｜引擎：Cocos Creator｜一个人开发，首版一个月

## 核心要求对照（先给结论）

| 核心要求 | 怎么满足 | 验收标准（埋点） |
|---|---|---|
| 1 简单，打着打着就会 | 全游戏只有一个主操作：长按蓄力、松手出钩；前 10 钩有辅助抛物线，之后慢慢变淡 | 首局 3 钩内命中率 ≥60%；第 20 钩命中率明显高于第 1 钩 |
| 2 核心循环，能长时间玩 | 秒级出钩 → 3 分钟一趟出航 → 每天扩筏救人 → 每周新海域和省份赛季 | 单次时长 ≥8 分钟，次日留存（D1）≥35% 作为首测目标 |
| 3 低配 | 2D、俯视 45°、不用物理引擎、同屏漂浮物 ≤20、本地优先存档、断网可玩 | 千元机稳定 30 帧；主包 ≤4MB |
| 4 爆款配方元素 | Raft 打捞生存 + 羊了个羊槽位与省份榜 + 海克斯三选一 + Smash Fest 连锁 + Coin Master 异步掠夺 | 每种配方都只借“机制骨架”，统一落在“出钩”这一个动作上 |

## 一、游戏多级分类（一级 → 二级 → 三级）

分类口径：按“玩家每一局主要在做什么”分一级，按机制分二、三级。一款游戏可以跨类。

1. **动作**
   - 平台跳跃 → 自动跑酷（Subway Surfers）、精准跳台、横版闯关
   - 射击 → 弹幕、俯视角射击、定点瞄准、大逃杀（Free Fire）
   - 格斗/混战 → 1v1、多人乱斗、技能连招
   - 物理破坏 → 弹射（Smash Fest）、投掷、连锁破坏
2. **角色扮演 RPG**
   - 动作 RPG → 刷装备、首领挑战
   - 回合制 RPG → 指令战斗、队伍搭配
   - 放置 RPG → 离线收益、英雄收集
   - Roguelike/Roguelite → 随机强化（海克斯大乱斗）、局内构筑、局外成长
3. **策略**
   - 塔防 → 路径塔防、合成塔防、割草塔防
   - SLG/4X → 建城、联盟、掠夺（无尽冬日、Last War）
   - 自走棋/卡组构筑 → 随机商店、羁绊、逐层挑战
   - 异步攻防 → 快照进攻、护盾、复仇（Coin Master、部落冲突）
4. **益智**
   - 消除 → 三消、叠层三消（羊了个羊）、连线
   - 空间规划 → 方块放置（Block Blast!）、分类排序（Bus Fever Party!）
   - 物理谜题 → 弹道规划、拆解结构
   - 逻辑/数字 → 数独、推理
5. **模拟经营**
   - 生存建造 → 漂流生存（Raft、疯狂水世界）、荒岛求生
   - 经营 → 餐厅、农场、员工派工
   - 养成 → 宠物、家园装扮
6. **休闲/超休闲**
   - 单指技巧 → 时机点按、长按蓄力（我们的位置）、拖拽
   - 钓鱼/打捞 → 钓鱼、抓娃娃、钩金矿（黄金矿工）
   - 转盘/抽奖 → 老虎机式转盘（Coin Master）
7. **竞技/社交**
   - MOBA → 5v5、大乱斗
   - 派对 → 多人小游戏合集
   - 社交排名 → 好友榜、地区榜（羊了个羊省份榜）
8. **平台/创作**
   - UGC 平台 → Roblox
   - 沙盒创作 → 自由建造

**我们的位置**：一级“休闲”×“模拟经营”交叉 → 二级“长按蓄力 + 生存建造” → 三级“打捞生存 + 异步攻防 + 每日挑战榜”。

## 二、热门游戏统计与优缺点

数据口径：来自你给的资料（Sensor Tower 2026 年报、2026 年 9 月全球手游下载榜、月狐数据 2026 年 3 月）。第三方数据都是估算，不是官方审计数。

**市场事实**
- 2025 年全球手游收入约 820 亿美元；策略是收入、下载、时长三项都增长的大类，主要靠《Last War》《Whiteout Survival（无尽冬日）》。
- 2026 年 9 月下载榜前五：Roblox、Free Fire、Block Blast!、Subway Surfers、Bus Fever Party!，五个里三个是“一根手指就能玩”的轻量游戏。
- 《无尽冬日》微信小游戏 MAU 约 4474 万：小程序里“生存题材 + 建设 + 策略”被验证过。

| 游戏 | 类型 | 主要人群 | 设计模式 | 优点 | 缺点（我们要避开） |
|---|---|---|---|---|---|
| Block Blast! | 方块放置 | 全年龄、碎片时间 | 单局计分、无限重开 | 零学习、上头 | 长线目标弱 |
| Subway Surfers | 单指跑酷 | 青少年、轻度 | 无尽挑战 + 收集 | 操作极简、反馈爽 | 内容重复 |
| Bus Fever Party! | 分类解谜 | 益智爱好者 | 关卡 + 空间规划 | 一看就懂 | 靠关卡量撑 |
| 羊了个羊 | 叠层三消 | 大众、社交传播 | 7 格槽位 + 省份榜 | 地域荣誉驱动传播 | 恶意难度、口碑快速崩 |
| Coin Master | 转盘 + 建村 + 掠夺 | 中年、女性偏多 | 短操作接长期建设、异步攻击 | 社交复仇、回流强 | 赌博感强、国内合规风险 |
| Smash Fest! | 物理弹射 | 超休闲 | 瞄准→连锁破坏 | 打击反馈强 | 深度浅、易腻 |
| 海克斯大乱斗 | MOBA + 随机强化 | 核心玩家 | 每局三选一强化 | 同一玩法每局不同 | 规则多、门槛高 |
| Raft | 漂流生存建造 | PC 生存玩家 | 钩子打捞 → 扩筏 → 探索 | 打捞手感 + 看得见的成长 | 3D、操作密度高、不适合小程序 |
| 疯狂水世界 | 海上拾荒经营 | 休闲经营玩家 | 拾荒 + 自由建造 | 题材有热度 | 核心操作被动，靠数值 |
| 无尽冬日 / Last War | 生存 SLG | 中重度、付费强 | 建城 + 联盟 + 战力 | 长线、变现强 | 前期轻、后期重，一个人做不了 |
| Roblox / Free Fire | UGC / 大逃杀 | 青少年 | 平台 / 赛季 | 社交极强 | 体量巨大，不可借鉴 |

**四条规律**
1. **入口操作要比理解成本低**：玩家先动手，后理解。
2. **深度来自“选择改变结果”**，不是来自按钮多。
3. **短循环必须接上长期目标**，但每一局本身要好玩，不能靠等待撑活跃。
4. **长期运营不是无限加难**：玩家要感到自己越来越会玩。

**爆款配方拆解 → 我们怎么用**

| 配方 | 出处 | 落地到《我的筏》 |
|---|---|---|
| 钩子打捞 + 筏子变大 | Raft | 主循环本体，“筏变大”就是游戏名的承诺 |
| 有限槽位 + 三个同类自动打包 | 羊了个羊 | “每日一海”模式：7 格货舱，同类三件自动打包，满了就输 |
| 省份排名 | 羊了个羊 | 每日一海同一个海图，按省排名 |
| 三选一强化 | 海克斯大乱斗 | 每次出航前三选一钩具改装 |
| 连锁反馈 | Smash Fest | 一钩撞到一串漂浮物，连钩加成 + 屏幕震动 |
| 异步掠夺 + 复仇 | Coin Master | 第二阶段：用同一个钩子钩别人的筏的快照 |
| 看得见的建设 | Coin Master / 无尽冬日 | 筏子扩建全程可视，前后对比可截图分享 |

## 三、游戏设计

### 3.1 定位
- **一句话卖点**：唯一一个“亲手钩”的漂流生存小游戏。别人是挂机捡破烂，你是凭手感捞宝。
- **差异点**：对《疯狂水世界》，我们有技巧型核心操作；对 Raft，我们是一根手指、2D、小程序秒开。

### 3.2 核心操作（唯一主输入）
- 长按：力度条从近到远来回走（往返，不是一次到顶，避免“按死”）。
- 松手：绳钩沿抛物线飞出，落点附近一个圆形判定区，碰到就钩住，自动回收。
- **打着打着就会**的三层引导：
  1. 前 10 钩显示虚线落点；
  2. 第 11–30 钩只显示落点光圈；
  3. 之后什么都不显示，靠手感。
- 判定宽容：落点差一点会“擦钩”，捞到一半（小块木板），让失败也有收获。
- 一根钩子三种用途：打捞（漂浮物）、捕鱼（鱼群移动，要提前量）、防御（鲨鱼咬筏时钩它的鳍，三下赶走）。

### 3.3 核心循环（四层）
| 层级 | 时长 | 玩家在做什么 | 驱动力 |
|---|---|---|---|
| 秒级 | 2–3 秒 | 一钩 | 命中爽感、连钩、稀有物闪光 |
| 分钟级 | 3–5 分钟 | 一趟出航：捞到货舱满 → 回筏卸货 | 满舱是决策点：要不要扔掉便宜货换稀有箱 |
| 天级 | 每次上线 | 扩筏、造设施、派员工、救人 | 筏子肉眼变大、员工帮你干活 |
| 周级 | 赛季 | 新海域、省份榜赛季、（二阶段）岛屿攻防 | 地域荣誉、收藏、社交 |

### 3.4 经济与约束（来自你定的方向）
- **承载**：筏子有承载上限，建筑和货物都占。扩浮台 = 加承载 = 筏变大。初期不能无限打捞，靠的就是这个。
- **食物驱动劳动力**：救上来的 NPC 员工按“游戏内工作日”吃口粮，有饭才干活（打捞、建浮台、种菜）。没饭就暂停，**但你自己永远能钩鱼自救**，杜绝死局。
- **体力**：只限制深海和特殊目标；近海普通打捞不耗体力，保证随时能玩。
- **电力**：不是核心，只用来解锁设备（净水器、自动钩、灯）。
- **不做重维修**。
- **单一货币**：海贸币。图纸不可卖。

### 3.5 让游戏名成立：第一天就要“变大”
- 第 1 分钟：2×2 木筏；第 1 天结束：约 6×6，带净水器、种植箱、一个员工。
- 每次扩建镜头自动拉远一下，让玩家“看见”变大。
- 关键节点自动生成“第 1 天 vs 今天”对比图，用于分享和投放素材。
- 远期形态：木筏 → 浮台群 → 快艇 → 邮轮 → 海上城（后期潜水）。

### 3.6 模式
1. **主线漂流**（离线可玩）：上面的全部。
2. **每日一海**（省份榜）：每天所有人同一张海图（同一个随机种子），7 格货舱，同类三件自动打包得分，舱满即结束。3 分钟一局，每天一次计分机会，看激励视频可再来一次（只取最高分）。
3. **岛屿攻防**（第二阶段，需联网）：异步快照，钩走别人筏上的货箱；掠夺上限 + 保护期 + 复仇。

### 3.7 省份排名规则
- 省份由玩家首次自选，每个赛季只能改一次（不依赖定位权限）。
- 省份分 = 该省当日前 N%（或前 1000 名）玩家的平均分，避免人口大省纯靠人数碾压。
- 防作弊：每日一海是确定性模拟，客户端上传“操作序列”，服务端重放核分。

### 3.8 低配与断网
- 2D 俯视 45°，统一图集，漂浮物对象池，同屏 ≤20 个。
- 不用物理引擎：抛物线公式 + 圆形碰撞自己写。
- 锁 30 帧（低端机）/ 60 帧（好机型）可切。
- 主包只放主线前 3 天内容，其余分包下载。
- 存档分两层：本地层（主线全部，断网可玩）+ 服务器层（排名、攻防、云备份），联网后排队同步。
- 游戏内时间按“上线时结算”，离线时员工最多干满 8 个游戏日，避免逼人频繁上线。

### 3.9 变现（首版）
- 只做主动激励视频：每日一海再来一次、一次救援、一次双倍打包。
- 不做强插屏、不做转盘抽奖。内购等版号再说。

### 3.10 一个月 MVP（一个人）
| 周 | 交付 |
|---|---|
| 第 1 周 | 出钩手感原型：蓄力、抛物线、判定、回收、连钩、擦钩；3 种漂浮物 + 鱼群。找 5 个人试玩 |
| 第 2 周 | 承载、货舱满、扩浮台（筏可视变大）、净水器、种植箱、1 个员工 + 口粮 |
| 第 3 周 | 每日一海 + 7 格打包 + 省份榜 + 重放核分；本地存档 |
| 第 4 周 | 新手引导、对比图分享、激励视频、性能调优、提审 |
| 推迟 | 岛屿攻防、潜水、快艇/邮轮、科研树、多海域天气 |

## 四、按思维模式复盘

### 第一轮：发散（5W1H）

1. **What 事实是什么？** 我们要做一款单输入（长按出钩）的 2D 漂流生存小游戏，主线离线可玩，外接每日挑战榜。小程序头部是“轻上手 + 重长线”的组合；超休闲下载高但留存弱；生存题材在小程序上被验证过。
2. **Why 为什么这么设计？** 玩家在小程序里的耐心只有几秒，所以操作必须一秒能懂；但只有单局刺激留不住人，所以要接上“筏变大”的长期投入；省份榜给传播动机；离线可玩适合地铁、电梯这种弱网场景。
3. **Where/When 边界条件？** 适用：竖屏、单手、碎片时间（1–10 分钟）、弱网。时间节点：第 1 分钟必须钩中第一个东西，第 1 天必须看到筏变大，第 7 天必须出现新玩法（新海域/每日一海赛季）。不适用：想要重度 PVP 和深度建造的硬核玩家。
4. **Who 涉及谁？** 玩家：轻度休闲（每日一海）、经营爱好者（主线）、地域荣誉党（省份榜）。开发：你一个人，同时是策划、程序、美术。平台：微信、抖音（审核、包体、广告规则）。竞品：《疯狂水世界》等同题材。
5. **How 怎么实现？** Cocos Creator 2D；自写抛物线碰撞；确定性随机种子；本地优先存档；分包；激励视频；一个月四周迭代，每周找人试玩。
6. **What if 前提变了？**
   - 长按手感测试不好 → 改成“绳钩自己摆动，点一下松手”的时机判定，其他系统不变。
   - 一个月做不完 → 砍每日一海的服务端核分，先做好友榜。
   - 玩家只玩每日一海不玩主线 → 说明它是爆点，把它做成主入口，主线当成长层。
   - 版号问题导致没法内购 → 纯广告变现，系统设计不依赖付费墙。

### 第二轮：收敛与拷问（每个节点：致命追问 + 双向钢人论证）

**① What：单输入真的够撑长线吗？**
- 致命追问：所有东西都用一个钩子，玩到第 3 天不会像流水线吗？
- 正方钢人：黄金矿工、钓鱼类游戏几十年证明“一个钩子”能玩很久，前提是目标在变：鱼会游、箱子会沉、鲨鱼会抢。
- 反方钢人：黄金矿工的长线来自关卡量，一个人一个月做不出大量关卡；目标变化不够就会腻。
- 裁决：变化靠“系统组合”而不是手工关卡：海域 × 漂浮物组合 × 三选一改装 × 天气，用数据表生成。

**② Why：“筏变大”真的是动机吗？**
- 致命追问：玩家会为一块变大的木板留下来吗？还是只是第一天新鲜？
- 正方钢人：Coin Master、无尽冬日都证明“看得见的建设”是强回流动机；游戏名本身就是这个承诺。
- 反方钢人：变大只是视觉，如果变大后玩法不变，就只是换皮的数值。
- 裁决：每次大扩建必须解锁一个新能力（净水 → 种菜 → 员工 → 自动钩 → 快艇去深海），变大 = 能做新事。

**③ Where/When：断网可玩和省份榜矛盾吗？**
- 致命追问：断网能玩，那排名靠什么保证公平？
- 正方钢人：主线和排名本来就是两层，主线断网，排名联网，不冲突。
- 反方钢人：离线成绩如果也能上传，作弊成本极低；只认在线成绩，弱网玩家又被排除。
- 裁决：每日一海允许离线打，联网后上传操作序列，服务端重放核分，当天 24 点前上传有效。

**④ Who：一个人一个月，范围对吗？**
- 致命追问：你列的东西真的一个人一个月能做完？
- 正方钢人：2D、单输入、无物理引擎、无实时联网，技术上是一个人能做的量。
- 反方钢人：美术才是瓶颈；生存类数值平衡很耗时；服务端重放核分也要时间。
- 裁决：美术统一一种低成本风格（扁平色块或像素），首版只做 3 种漂浮物 + 2 种鱼 + 5 个建筑；攻防整体推迟。

**⑤ How：激励视频会不会破坏体验？**
- 致命追问：靠广告变现，会不会做着做着就变成“看广告才能玩”？
- 正方钢人：只做主动激励视频，玩家自己选，体验最好、平台也鼓励。
- 反方钢人：只做主动广告，收入可能撑不住，后面会被迫加强制广告。
- 裁决：广告点只放在“锦上添花”位置（再来一次、双倍），永远不放在“没广告就卡死”的位置；收入不够时先加皮肤/装饰，而不是加墙。

**⑥ What if：省份榜还管用吗？**
- 致命追问：羊了个羊的省份榜是 2022 年的爆点，现在玩家还吃这套吗？
- 正方钢人：地域荣誉是长期有效的社交动机，体育、高考都在用；而且几乎零成本。
- 反方钢人：玩家已经见过，新鲜感下降；而且羊了个羊靠的是“难到通关稀缺”，我们没有这个。
- 裁决：省份榜做成“每日轻竞赛”而不是“通关稀缺”；再加一个独特点：省份的筏会在海图上拼成一座“省份海上城”，全省玩家一起让它变大，名字梗和地域荣誉结合。

### 第三轮：重构（复盘后的修正版）

相比复盘前，做了这几处改动：
1. **核心循环从“打捞”改成“打捞 + 满舱取舍”**：每趟出航都有一个决策点，不再是纯手速。
2. **“变大”必须绑定新能力**：每个扩建阶段解锁一种新玩法，不只是数值。
3. **省份榜从“排名”升级为“全省共建海上城”**：这是我们自己的创意点，也是传播素材。
4. **岛屿攻防推迟到第二阶段**：一个月里先保证主线 + 每日一海做扎实。
5. **长按手感作为第 1 周的生死测试**：不过关就切成“摆钩点按”，不硬撑。
6. **永不死局**：没饭员工停工，但玩家自己永远能钩鱼，最差也能慢慢翻身。

## 五、你还需要注意和优化的地方

1. **合规**：小程序要先做主体认证、ICP 备案和软著；带内购的游戏要版号，没有版号就只能先做广告变现（以平台最新规则为准）；未成年人防沉迷；如果以后有随机抽取要公示概率。Coin Master 的转盘赌博感在国内很危险，我们已经去掉。
2. **名字查重**：正式上线前查一下商标和微信/抖音小游戏重名。
3. **题材撞车**：和《疯狂水世界》同题材，素材上一定要突出“亲手钩”的手感镜头，不要拍建造画面（那是它的主场）。
4. **包体**：微信主包 4MB 左右的限制要从第一天就盯住，音效用短 mp3，图集压缩。
5. **竖屏单手**：抖音用户多是单手竖屏，出钩按钮放在拇指区，整屏任意位置长按也可以。
6. **录屏适配**：抖音小游戏靠录屏传播，连钩、捞到稀有箱、对比图都要有“自动录 5 秒高光”的点。
7. **第一周的数据埋点**：首钩命中率、第 1 局时长、第 1 天扩建次数、D1、每日一海参与率。只看这五个。
8. **难度曲线**：不要学羊了个羊的“故意过不去”，要学它的“差一点就过”。每日一海的分数要有明确的进步感。
9. **离线收益上限**：员工离线最多干 8 个游戏日，既不逼人上线，也不让离线太久的人一回来就爆仓。
10. **一个人的风险**：每周固定找 5 个真人试玩，比自己闭门做一个月可靠得多。
