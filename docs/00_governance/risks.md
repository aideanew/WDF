# 风险登记

权威内容在`docs/01_product/design-source/立项评审-Hark回答.md`（v5，第五点五节数值风险与第十一节）。本文件只登记**工程侧**风险。

| 风险 | 信号 | 应对 |
|---|---|---|
| 主包超 4MB | 构建报告主包 >3.5MB | 引擎插件/原生代码分包；图集瘦身；脚本拆分审查 |
| 双端规则漂移 | determinism 测试失败 | 只改 game-core，禁止复制规则 |
| 存档损坏/丢失 | 迁移测试失败、云端分叉激增 | 主副两份 + 校验和；分叉保留 |
| 资源引用断裂 | 预制体丢图、uuid 报错 | 只在编辑器内移动资源；.meta 必提交 |
| 20:00 峰值 | 压测 P95 超标 | 限流、预热、快照读排行 |
| 单人瓶颈 | 第 1 周无真机出钩闭环 | 停新系统，回核心 |
