# sources/ 原始资料（只读，免 front matter）

| 目录 | 内容 |
|---|---|
| `conversation-log/` | 本项目与 Hark 的完整对话记录，按日期逐字导出（由 `tools/gen/conversation-log.mjs` 从对话日志生成） |
| `original-requirements/` | 原始需求、用户与其他 AI 的讨论原文（“完整版-标注说话人”用于区分用户决定与他人建议） |
| `external-reviews/` | 外部评审报告与三份目录规划方案原文（取舍结论在立项评审 v5 与 project-structure-spec 第二节） |

**归属规则**：只有用户说过的才是决定；其他 AI 或评审的内容是建议。
