## 1. jobs 表（7 岗位，§5.3:421-430）

| 列 | 类型 | 来源 | 依据 |
|---|---|---|---|
| `id` | enum(7) | **§5.3:421-430 岗位表** | soldier/cook/smith/carpenter/mechanic/researcher/worker |
| `name` | string | 同上 | 士兵/厨师/铁匠/木匠/机械师/研究员/工人 |
| `produces` | string(`;` 分隔，无外键) | **§5.3:437** | 铁匠=钢材/银锭/金锭、机械师=齿轮/钢缆/电线/电池 |

| `food_consumption` | int | **无源** | §5.2:416 按工作日结算，无每人速率 → 留空 |
| `job_level` | int | **无源** | §5.3:435 等级概念，无数值 → 留空 |

### produces 明细（§5.3:437 原文：总表里高级材料对应的员工）
- 铁匠（高炉：钢材、银锭、金锭）→ `item_0031;item_0032;item_0033`
- 机械师（机械工坊：齿轮、钢缆、电线、电池）→ `item_0036;item_0037;item_0034;item_0035`
- 士兵/厨师/木匠/研究员/工人：产出物**不固定**（§5.3:422-430「干什么」为职责描述，非固定 item）→ 留空 + 登记
