## 三之二、D-08 与设计源冲突（待用户裁决）

- **现象**：`locks.hits_required` 当前 = D-08 占位值（none=0/iron=3/copper=5/silver=8/gold=12，plan-v003），但设计源 v5.5 §8.4:583-588 明确「需连续命中：铁 1/铜 2/银 3/金 4」。
- **判定**：D-08 是 plan-v003 旧裁决（当时设计源未给数值，属占位）；§8.4 为最新设计源唯一权威（AGENTS.md）。**设计源应为 1/2/3/4**。
- **本卡处置**：hits_required **保留 D-08 值不改**（PD7-09 卡只授权 zone_bp/drop_group 补全，未授权改 hits_required）；登记冲突，**建议后续卡或用户拍板按 §8.4 修正为 1/2/3/4**。
