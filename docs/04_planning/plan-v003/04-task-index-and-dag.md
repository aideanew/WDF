## 4.2 依赖 DAG（文本）

```
用户裁决 D-01~D-10 ──► 4002 ──┬─► 4003 ─┐
        （4001 先行）          └─► 4004 ─┤
                                        ├──► W1 批末全量 verify
用户裁决 D-11 ──► 4005 ──► 4006 ──┬─► 4007 ─┐
                                  └─► 4008 ─┴─► W2 批末全量 verify
用户裁决 D-08/09 ──► 4009（可与 4006 并行？否——见 4.3）

S14 并行轨：4010 / 4011 / 4012（三者互不依赖，可同时开工）
4012 ──(超标?)──► 4014
4010 ──► 4013
4006 + D-11/D-12 裁决 ──► 4015 ──► 4016
```

- **关键路径**：裁决 → 4002 → 4005 → 4006 → 4007/4008 → verify → 4015 → 4016。工期由**用户裁决速度**决定，不由编码速度决定（这正是本规划的辩证核心：瓶颈在人不在码）。
- **环检测**：无环（4005→4006→4015 为单向；4014 依赖 4012 单向）。
