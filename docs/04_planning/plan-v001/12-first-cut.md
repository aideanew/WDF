## 12.3 需要人亲手做的步骤（大白话）

### Cocos Creator（只做一次，约 20 分钟）

1. 打开 **Cocos Dashboard** → **新建项目** → 模板选 **Empty** → 项目路径填 `e:\Demo\WDF\client` → 点**创建**。
2. 等编辑器打开后，右上角**项目设置**（齿轮图标）→ **项目数据** → 设计分辨率设为 **720 × 1280**，适配选 **Fit Height**。
3. 左侧 **资源管理器** → 右键 `assets` → **新建 → 文件夹** → 命名 `scenes`；再右键 `scenes` → **新建 → 场景** → 命名 `Boot` → **保存**（Ctrl+S）。
4. 左侧 `assets` 下若有 `bundles` 文件夹就用它；没有就右键 `assets` → 新建文件夹 `bundles`。进入 `bundles`，右键 → 新建文件夹，依次建 **7 个**：`b-common`、`b-shallow`、`b-deep`、`b-island`、`b-defense`、`b-event`、`b-social`。
5. **逐个点选每个 `b-` 文件夹**，在右侧 **检查器** 里勾上 **"配置为 Bundle"**，Bundle 名保持与文件夹同名，**不要**改成 `main`/`resources`/`internal`。
6. 顶部菜单 **项目 → 构建发布** → 平台选 **微信小游戏** → **起始场景**里把 `Boot` 拖进去 → 先不构建，关掉即可。

### 微信开发者工具（S10 才需要，现在不用）

1. 下载并安装**微信开发者工具** → 用**小游戏 AppID** 登录（测试号也行，但真机预览需要正式 AppID）。
2. Cocos 里 **构建发布** → 平台 **微信小游戏** → 填 AppID → **构建** → 得到 `build/wechatgame/`。
3. 开发者工具里 **导入项目** → 目录选 `build/wechatgame` → 打开。
4. 点 **预览** → 手机扫码 → 在真机上走 6 步脚本。
5. 判断标准：能出钩、能拿到东西、杀掉小程序再进东西还在、主包体积在工具"详情 → 基本信息"里 **≤4MB**。

## 12.5 S1 的 6 步演示脚本（验收用，照抄）

```
1. 启动 App → Boot 场景 → 顶部显示"合规状态：已通过"
2. 长按屏幕 → 力度条走到头再回 → 松手 → 钩子飞出 → 碰到漂浮物 → 拉回
3. 背包里出现 1 件物品，界面数字变化
4. 直接杀进程（不是退出，是任务管理器杀掉）
5. 重新打开 → 背包里那件物品还在
6. 联网状态下点"同步" → 服务器 save_snapshot 表里多一行，revision 递增
7. 故意把请求的 a 改成 aaa → 收到 { c: 1002, msg: ... }，界面弹出可读的错误提示
```

## 12.6 第一刀不做什么（防止范围蔓延）

- 不做开锁、不做合成、不做等级、不做赶海、不做塔防；
- 不做美术（用色块/占位图即可）；
- 不做多平台（只跑微信 + 浏览器预览）；
- 不做优化（无基线，见 09）。
