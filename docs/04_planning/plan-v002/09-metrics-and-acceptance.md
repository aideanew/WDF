## 9.4 完成定义（全项目唯一口径）

```
Done =
  所有权内 diff 符合任务
  ∧ 验收条目逐条有结果
  ∧ 自动测试/脚本可复现
  ∧ evidence 能让一周后的人复现，不用问原作者
  ∧ npm run guard 通过
  ∧ 未修改冻结契约（除非本任务就是改契约）
```

**Done ≠ 模型说完成 ≠ 代码写完 ≠ 推到 GitHub。**

## 9.5 防自证循环

- 验收标准由**本规划（现在）**定；执行由开发 CLI 做；判定由**独立验证者**只看 diff+运行结果，输出 `PASS/FAIL/UNKNOWN`。
- 禁止同一 Agent 写标准+执行+自判通过。
