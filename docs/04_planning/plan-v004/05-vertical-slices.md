# 05 · 垂直切片 S17~S19（v1.0 闭环结尾）

本轮切片承接 S11~S16 的遗留项，将其重新打包为最终收官切片。

## 5.1 切片清单与排序

| 切片 | 内容（端到端可演示行为） | 前置条件 | 理由 |
|---|---|---|---|
| **S17 核心玩法 UI 落地** | 商人页购买、背包回收确认弹窗、打捞开锁连点交互。 | S12 (后端与数值已好) | v1.0 玩家主路径必不可少的一环，将后端能力暴露给用户。 |

- **S18**：`npm run verify` 中契约测试绿，文档状态更新。
- **S19**：EVD 目录下存在 MP4 文件及合规说明。
