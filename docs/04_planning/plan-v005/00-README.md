## 4. 层级编号规范（≥3 级，全体系统一）

```text
第 1 级 = 文件序号      00 … 14        （= 执行步骤 / 基线章节）
第 2 级 = 章            1. 2. 3.        （= 该步骤下的能力面）
第 3 级 = 节            1.1 1.2           （= 原子动作组）
第 4 级 = 原子步骤      1.1.1 1.1.2      （= 一次可提交的改动，≤30 分钟）
```

- 原子步骤（第 4 级）是**最小可提交单元**：一条原子步骤 = 一次 commit 的合理边界。
- 每条原子步骤必须绑定**至少一条可执行验证**（命令或断言），否则不得进入执行。
- 任务卡编号续用 `TASK-4xxx`（不复用 plan-v004 已用号），新增卡从 `TASK-4017` 起。
