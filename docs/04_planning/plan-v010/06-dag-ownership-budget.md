## 2. 可并行组（每条附机械规则满足依据）

机械规则：**可并行 ⟺ 无共享可变状态 ∧ 依赖的契约已冻结 ∧ 文件所有权不相交 ∧ 不共用同一迁移号**。

| 组 | 任务 | 共享可变状态 | 契约冻结 | 所有权相交 | 迁移号 | 判定 |
|---|---|---|---|---|---|---|
| **P1** | 7001 / 7012 / 7022 / 7041 | 无（7001 新建工具文件；7012/7022 只写 ADR；7041 只改 `panel-ui.ts`） | N/A | 否 | 无 | ✅ **可并行 4 写** |
| **P2** | 7002 / 7004 / 7050 | 无（7002 改注释；7004 改 `gen/config.mjs`；7050 新建 `stage.mjs`） | N/A | 否 | 无 | ✅ **可并行 3 写** |
| **P3** | 7013 / 7020 | 无（不同模块目录） | ✅ 都已冻结 | 否 | **7013 持 0002；7020 不建表** | ✅ **可并行 2 写** |
| **S1** | 7005 → 7010 | **`RpcClient.ts`** | ✅ | **是** | 无 | ❌ **串行** |
| **S2** | 7002 → 7042 | **`GameApp.ts`** | ✅ | **是** | 无 | ❌ **串行** |
| **S3** | 7013 → 7014 | 无（不同目录） | ✅ | 否 | 无 | ✅ 可并行（但 7013 未完成时 7014 无数据可测 → 实际串行） |

**同时最多 3 个写入 Agent**（用户约束）→ P1 的 4 个任务需分两批：`7012`+`7022`（都只写 ADR，可由主控一人做完）+ `7001`+`7041`。

## 6. 熔断规则

```
同一任务连续 2 次验收失败
  → 停止改代码
  → 三选一：重写任务卡 / 升级档位 / 标记 blocked 并写清卡在哪
  → 禁止换提示词硬撞第 3 次
```

**本版已预置的熔断点**：

| 任务 | 预判最可能的失败原因 | 熔断后动作 |
|---|---|---|
| 7001 | module-catalog 声明面与目录不一致（清单本身失真） | 停下来出"清单 vs 结构"对照表，不补目录 |
| 7004 | 新文件污染 `configVersion` 的 sha | 改方案：占位清单放 `docs/` 而非 `config/` |
| 7020 | `AdClaimRes` 没说发什么奖 | 停下来问，不编数值 |
| 7042 | 三项承诺其实都不在 v1.0 需求里 | 只做 `save.flush`，其余写进 `02 §4.2` 缺口的"不做"列 |

## 7. 基线指标

**现状：本项目没有任何用户可感操作的性能基线。**

| 候选指标 | 是否可测 | 是否"降了用户可感" | 判定 |
|---|---|---|---|
| 首次可操作 P90（`mvp-scope` 要求 ≤5s / 弱网 ≤8s） | 需真机 + 埋点 | 能证明 | **可作为基线，但需真机 → 本期无法测** |
| 接口 P95 <300ms | `npm run probe` 可测本地 | 能证明 | **可作为基线**（本地值≠线上值，须标注） |
| 同屏漂浮物 ≤20 时帧率 | 需真机 | 能证明 | 本期无法测 |
| 主包体积 ≤3.5MB | `npm run check:bundles` 可测 | 能证明 | 可测（v001 记录 3.1MB，现在未知） |

⇒ **本版不排任何"优化"任务**（符合 §9.1：没有基线数字，禁止排优化任务）。
`services/pool`（对象池）因此只标注不实现（TASK-7005）。

**首次测量值**：`无`。本版未运行 `npm run probe` / `check:bundles`（用户要求拒绝全量门禁）。
→ 标记为 `尚无基线`。若后续要开性能优化，**必须先补这三个数字**。

## 8. 并行纪律（写给执行者）

✅ **允许并行**：不同所有权目录、共用已冻结契约、不写同一迁移号。
❌ **禁止并行**：

- 同时改 `packages/contracts/**`（本版整体不动契约）
- 同时改同一张表 / 同时持两个迁移号
- 一边改 `RpcClient` 一边改 `BootController`（都碰登录链）
- 一边改 `handlers.ts` 一边改任何 `modules/*/handlers.ts`（注册表与实现耦合）

## 9. 关键路径

```
7001 → 7002 → 7042 → 7041 → 7051
```

理由：7001 是判定地基；7002 让注释与代码一致（否则 7042 会照错注释实现）；
7042 是启动链（错则全站不可用）；7041 是六态基建（影响所有面板）；
7051 收口文档。**这条链上任何一环延后，整体交付就延后。**
