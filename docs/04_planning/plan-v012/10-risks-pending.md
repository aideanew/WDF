**⚠ 本轮修订（2026-10-30，实测定稿前）：选项 A 原假设"文字结算不需要数值"是错的。**

| 选项 | 含义 | 后果 |
|---|---|---|
| **A′（修订后的建议）** | 按 `mvp-scope.md §5` 已授权的降级方向，但**只结算"可确定的量"**：占岛（`islands` 4 模板）、建防御（按 `defenses.recipe` 扣材料，**3/3 可解析**）、布局合法性（`distanceField` 已实现）、保护期（`protection_cards.duration_hours` 24/168/720）；**袭击胜负返回 `verdict: 'unknown'`** | PD8-14 交付真功能；缺口显式暴露；不需要任何新数值 |
| A（原方案） | 文字结算 `{胜/负, 剩余兵力, 损失建筑, 掠夺资源}` | **实测不可行**：胜负无数值可算 |

| C | 自己编数值 | 违反 N-4 |

**建议 A′**。依据：`mvp-scope.md` §5 原文
「野人岛 + 迷宫塔防 + 回放（**第 3 周末不稳就临时改成文字结算**）」——降级方向是被授权的；
但"文字结算"本身仍要吃数值，这条被实测推翻，因此收敛为 **A′（可算的算，不可算的 `unknown`）**。
**卡住哪张**：PD8-14 的"袭击胜负"部分。**不卡**其他 17 张卡（18 张里除它自己）。

### D-59（本版新增）· v1.0 完成判据取哪套

**一句话**：`D-50` 把 13 模块推到 v1.1 了，`mvp-scope.md §5` 说 v1.0 必须有它们。以哪个为准？

| 依据 | 主张 | 时间 / 权威 |
|---|---|---|
| `mvp-scope.md` §5（PRD-0004，`status: active`） | v1.0 含塔防/3兵种/岛屿/7员工/等级49/每日一海/称号/榜单 | 2026-10-23「已定·Hark代定」 |
| `D-50`（`DECIDED`） | 13 个模块延期 v1.1 | 2026-10-28 用户拍板 |

**两套口径算出的完成度几乎一样**（37.5% vs 34.8%，见 `03 §3.1`）——**它们描述同一批欠账，只是切法不同**。
所以这个裁决**不改变工作量，只改变"什么时候能说 v1.0 完成"**。

| 选项 | 含义 | 后果 |
|---|---|---|
| **A（我的建议）** | 以 `D-50` 为准：v1.0 = 五环 + 商人 + 箱子 + 榜单 + 联网，其余 v1.1 | 可以先上线；`mvp-scope §5` 需标注"被 D-50 部分覆盖"（**但那是 `docs/01_product/`，不在本版写入白名单**，只能在 `current-plan.md` 记录） |

| C | 两阶段都叫 v1.0（先发"v1.0-a"，再发"v1.0-b"） | 与 `mvp-scope` 的上线顺序声明冲突 |

**建议 A**。**卡住什么**：只卡"能不能宣布 v1.0 完成"这个口径，**不卡任何卡**。

### D-60（本版新增）· 经验值取什么

**一句话**：`levels` 有 49 级曲线（累计 28,420 exp），但**一次打捞/一次建设给多少经验，设计源没给**。

| 事实 | 证据 |
|---|---|
| 设计源只有定性 | `design-source/我的筏-深度设计方案-v5.5.md:69`：「【已定】经验来自打捞 + 建设（**例如**每升级解锁一件新装备涨经验）」——"例如"三字说明它没定数值 |
| `items` 表无 `exp` 列 | `head -1 game-data/source/items.csv` → `id,name,category,base_price,weight,capacity,stack,craftable,unlock_level` |
| 已有可用真实数值 | `items.base_price`（106 行，min 0 / median 108 / max 30000）；`item_0001` 漂流木 = **10** |
| 曲线量级 | `exp_to_next(1) = 100`；累计到 49 级 = **28,420** |

| 选项 | 含义 | 后果 |
|---|---|---|
| **A（我的建议）** | `expGain = 产出物品的 base_price`（**1:1**） | 打漂流木 10 次升到 2 级（100/10）；**零新增数值**，全部来自已有列 |
| B | 固定值（打捞 1 / 建设 5） | 升到 2 级要打 100 次 → 节奏不成立 |
| C | 等设计源补 | PD8-08 的"升级"永远不发生 → 只交付闸门不交付升级 |

**建议 A**。**卡住哪张**：PD8-08 步骤 3 一行公式。**不卡**其他 17 张卡（18 张里除它自己）。
