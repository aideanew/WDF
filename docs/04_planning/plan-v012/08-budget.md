## 3. 熔断规则（写进每张卡）

```
同一任务连续 2 次验收失败 → 停止改代码

```

## 4. 阶段体检协议（用户明确要求，写死）

| 时机 | 跑什么 | 不跑什么 |
|---|---|---|
| 单卡完成 | `npm run impact <关键词>` 圈定的测试 + 该卡 `验证命令` 里的定向命令 | `npm run verify` / `npm run test` 全量 |
| 一个批次（G1~G6）完成 | 本批次动过的模块的定向测试汇总 + `node tools/guard/placeholders.mjs` | 同上 |
| 阶段出口（A / C 完成时） | `npm run verify` **一次** | — |
| 发版前 | `npm run verify` + `npm run release:check` | — |

**为什么这样切**：`npm run test` 是 39 文件 263 用例，全量跑一次约 40~60 秒（本机实测过）；
单卡只跑 1~3 个文件即可，把每次提交的门禁时间从分钟级压到秒级。这是用户 2026-10-27 与 2026-10-30
两次强调的方式，本版按此执行。
