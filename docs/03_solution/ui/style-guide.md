# UI 规范

- 设计分辨率 750×1334（750 设计像素 ≈ 375 逻辑像素，×2）。
- 正文 32 设计像素（16 逻辑像素）；辅助 ≥28（14）；触控区 ≥96（48）。
- 出钩按钮右下拇指区；顶部只放低频信息；避开胶囊、刘海、底部手势区。
- 不只靠颜色：力度条加刻度/近中远文字；品质加边框/角标。
- 色板与动效细则：见`docs/01_product/design-source/立项评审-Hark回答.md` 与后续 UI 稿（画风【已定 2026-10-23 10:23，拍板 6】：**卡通 2D 海洋风**——暖木色、蓝绿海面、粗描边）。
