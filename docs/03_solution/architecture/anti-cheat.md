# 信任边界与防作弊

见 `architecture-overview.md` 第 6.4 节。要点：
- 客户端只做存档校验和（防误损坏）与服务器时间对齐；不做内存监控。
- 赶海：服务器生成场次、种子、装备快照（检查装备档位不超过等级可解锁范围），客户端上传操作事件，服务器用 game-core 复算计分。
- 总收益榜：服务器按“每小时理论最大收益”设上限，超过标记复核、暂缓发奖。
- 必须承认：主线允许断网，就做不到绝对公平，只能抬高作弊成本。
