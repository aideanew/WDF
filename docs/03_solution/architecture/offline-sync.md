# 离线与同步

见 `architecture-overview.md` 第 6.5 节。补充：
- 断网期间只产生本地存档变化；服务器权威动作（赶海、排行上报、限量领取、聊天、绑定）在离线时给出明确提示，不排队伪造。
- 埋点与“联网实时收获”上报使用发件箱：内存队列 + 本地持久化，20 条或 30 秒或切后台时批量发送；断网时收获事件**不补计榜**（已定离线不计榜）。
- 离线结算（员工、食物、电力、野人袭击）在下次启动时由 game-core 按“服务器时间 − 上次存档时间”计算；时间回拨按 0 处理。
