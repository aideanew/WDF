# 联网与存档同步

> 2026-10-23 10:40 起改为“必须联网”（拍板 4 选 B，见 `docs/03_solution/decisions/ADR-0008-online-required.md`）。原“离线可玩 + 离线同步”设计作废，历史内容留在 `docs/09_archive/`。

见 `architecture-overview.md` 第 6.5 节。补充：
- 所有写操作（打捞结算、制作、建造、开箱、占岛、领取）必须联网，经服务器确认后才落库；客户端本地只保留**只读缓存**。
- 断线、弱网、切后台重连时给明确提示并暂停写操作；不做“离线排队 + 补交”，避免伪造。
- 写操作幂等：每个请求带 `rid`，服务器按 `rid` 去重；超时重发不会重复扣/加。
- 埋点与收获上报继续用发件箱（内存队列 + 本地持久化，20 条或 30 秒或切后台批量发送）；断线时队列保留，恢复后补报。
- 非写操作结算（员工产出、食物、电力、野人袭击）改由**服务器**在玩家不在线时按“服务器时间 − 上次在线时间”计算；客户端不再自行结算。
