# 发行路线：个人主体 + 微信先发

## 背景
《我的筏不可能这么大》是纯广告变现的休闲小游戏，一人开发。用户 2026-10-23 10:23 拍板：主体用**个人主体**（纯广告小游戏，不用版号）；首发**微信先上，抖音晚 2–4 周**。

## 选项
A 个人主体 + 微信先发（已选）；B 个体工商户 / 公司 + 双平台同步首发；C 先只上微信，抖音二期。

## 决定（已定 2026-10-23 10:23，拍板 1 + 拍板 7）
A：个人主体上架，纯广告、不办版号；微信先发，抖音晚 2–4 周。
配套【建议】：软著仍办（微信纯广告游戏一般不要，抖音要，且游戏名必须与软著完全一致）。

## 后果
- 不需要版号 → 省掉最长的一段审批；但**不能做内购**，变现只有激励视频。
- 个人主体拿不到企业级能力 → 聊天只做快捷短语 + 表情，不做自由打字。
- 抖音晚 2–4 周 → 字节侧的软著 / 备案必须在微信上线前就并行启动，否则抖音会卡在软著（自办约 1–3 个月）。
- 平台差异只落在 `client/assets/scripts/platform/<wechat|douyin|app>/`，业务层不感知。
- 以后要上 APP 或做内购，需升级主体并补版号，届时另开 ADR。
