# 引擎：Cocos Creator 3.8 LTS

## 决定
使用 Cocos Creator 3.8 系列 LTS 稳定补丁版。~~第 1 天出微信/抖音样包，验证登录、广告、分包、后台恢复、字体音频、最低档真机，通过后锁定补丁号并记录于此。~~（10-23 11:18 收敛为下列三步，登录/广告/分包等改在后续切片验证）

**版本锁定流程（已定·Hark代定 2026-10-23 11:18）**

1. 取 **Cocos Dashboard 里最新的 3.8.x 正式版**（不是 beta / 不是 preview）。
2. 用该版本建一个**空场景样包**：新建空项目，只留一个空场景，不加任何脚本。
3. 构建为**微信小游戏**，在**微信开发者工具**里能打开。
4. 在一台**安卓真机**上能打开。

**判定与收尾**
- 四步全过 → 把具体版本号（如 `3.8.6`）填进本文件「决定」首行 → 本文件 `status` 改 `accepted` → 勾掉 `docs/01_product/project-charter.md` 的立项退出条件。
- 任一步没过 → `status` 保持 `proposed`，版本号留空，**不锁定**。
- **此后不升级引擎**，除非另开 ADR（升级按 L 级变更处理）。

### 怎么点（大白话，给非引擎使用者）
1. 双击桌面 **Cocos Dashboard** → 左侧 **安装（Installs）** → 在 3.8 系列里挑**版本号最大且不带 beta/preview 字样**的那个 → 点 **下载/安装**。
2. 安装完 → 左侧 **项目（Projects）** → 右上 **新建（New）** → 模板选 **Empty（空）** → 填名字（随便，比如 `probe`）→ 选刚装的 3.8.x → 点 **创建并打开**。打开后**什么都别动**，直接 `Ctrl+S` 保存场景。
3. 菜单 **项目（Project）→ 构建发布（Build）** → 平台选 **微信小游戏** → 填 **AppID**（没有就填测试号/游客）→ 点 **构建**。构建完成后点 **运行**，它会拉起微信开发者工具（没装会提示你去装）。
4. 微信开发者工具里**能正常显示出空场景**（不是白屏、不是报错）即算第 3 步过。
5. 微信开发者工具右上 **预览** → 手机扫码 → 用**安卓手机**打开 → 能看到画面即算第 4 步过。
6. 回到本 ADR 填版本号、改 `status: accepted`、去 `project-charter.md` 勾立项退出条件。

## 后果
开发期不追新版本；升级须走 L 级变更。
