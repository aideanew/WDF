# 后端：模块化单体 HTTP 服务（腾讯云轻量 + Docker Compose）

## 选项
A 平台云函数（微信云开发/抖音云）；B 每域一个 Serverless 函数；C 模块化单体容器服务。

## 决定（已定·Hark代定 2026-10-23 10:45）
C：Node 22 + TypeScript + Fastify，无状态容器，单入口 `/v1/rpc`。微信与抖音调用同一域名。

部署平台：**腾讯云轻量应用服务器（2 核 4G，广州或上海）+ Docker Compose**，单机同时服务微信与抖音。

理由：
- 小游戏的合法请求域名必须是**已备案的国内域名**，境外主机与未备案域名过不了平台校验。
- 一台机器同时服务两个平台，成本最低，符合个人开发者体量。

配套：域名以**个人主体立即办 ICP 备案**（不等开发完成再办，备案本身要时间）。

## 后果
需要备案域名与 HTTPS；部署通过环境变量切换配置，不改代码。单机上限明确：日活超出单机承载时先做读写分离与 Redis，再考虑拆分（见 ADR-0004）。
