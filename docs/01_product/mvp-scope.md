# 核心工作与 MVP 范围

## 1. 核心工作（必须最先证明，否则其他都白做）
| # | 核心 | 证明标准（【建议】指标） | 依据 |
|---|---|---|---|
| C1 | 出钩手感：长按蓄力、弧形力度条蓝→绿→红约 1.2 秒往返、严格判定、不限次数 | 30 秒学会 ≥70%；教学后首钩命中 ≥45%；前 10 钩成功 40–60% | v5.5 1.2【已定】 |
| C2 | 捞—做—扩循环：打捞 → 制作 → 扩筏（浮力 ≥ 重量）→ 能捞更多 | 新玩家连续玩 15 分钟不卡、不迷路 | v5.5 1.3、4.1【已定】 |

## 2. MVP = 用户已定的首版范围（v5.5 11.1，【已定】，不删减）
| 模块（module-catalog id） | 首版内容 | 周次（11.4） |
|---|---|---|
| hook / sea / fishing | 核心出钩；浅海打捞、潮汐（每 6 小时、10 分钟）；钓鱼 | 第 1 周 |
| crafting / inventory | 物品体系与制作（第十三章全部配方、研究台、工作台附件、自动合成） | 第 1–2 周 |
| raft / crew / power / progression | 浮力/重量、扩筏、多层（研究室解锁）、员工与食物、职业、等级与驶出浅海、海图导航 | 第 2 周 |
| chest | 开锁（四档锁、三级工具）+ 箱子（木/铜/铁，平时木箱可砸） | 第 2 周 |
| salvage / economy | 深海五项：野人船、石油、沉船（含潜水员、偶遇沉船）、探索、钓鱼；商人与价格表 | 第 3 周 |
| island / defense | 占岛、岛屿基地、大仓库一键入库、野人袭击塔防（离线结算、无预警、回放、投掷）、9 兵种全做、保护卡（7 天/24 小时） | 第 4 周 |
| social / leaderboard / guide / settings | 区服聊天+世界频道、榜单（全服/区服/地域）、新手引导、画质三档 | 第 4 周 |
| event / leaderboard(称号) | 每日一海（赶海多捞哦）、称号系统 | 第 5 周 |
| account / compliance / ads / telemetry | 绑定账号、防沉迷、激励视频、首周埋点 | 贯穿 |

**不在首版【已定】**：远洋（50 级）、PVP、交易、结盟、招揽工匠、埋宝、AI 虚拟玩家、30 天保护卡（v5.5 11.2）。

## 5. v1.0 / v1.1 内容分期【建议，待确认】（2026-10-23 10:23，按拍板 2 起草）

> 依据：`立项评审-Hark回答.md` 第四节 + 拍板 3（9 兵种全做，不改原设计）+ 拍板 5（做区服）+ 拍板 4（保留总收益榜）。
> **以下全部是【建议】；你确认前，第 2 节的任何一条都不删减。**

**v1.0（5 周，先上线）**
- 出钩全套、浅海、潮汐、钓鱼
- 物品与制作（第十三章全部配方、工作台 / 研究台、自动合成）
- 船体：房间统一大小、积木加层、浮力 ≥ 重量、研究室解锁加层
- 员工 7 岗位（自动工作；幸福感先只做数值，不做事件）
- 电力：太阳能 + 电鳗（石油发电随深海石油一起）
- 箱子与开锁（木 / 铜 / 铁箱，四档锁、三级工具）、商人回收
- 深海：沉船（含潜水员）、石油、探索、钓鱼
- 占 1 座无主岛 + 大仓库一键入库 + 保护卡（新手 7 天卡、24 小时卡）
- 野人塔防：迷宫 + 回放 + **9 兵种全做**（拍板 3）+ 弓弩车 1 级 + 投石机基础 + 4 种岛屿模板
- 赶海（服务器版）+ 榜单（总收益榜、赶海单日榜、等级榜、省份榜）+ 称号
- 区服（管理员控制开新区，新玩家进当前开放的新区，拍板 5）
- 新手引导、画质三档、激励视频、合规页面、首周埋点

**v1.1（上线后 2–3 周补上）**
- 弓弩车 2 / 3 级 + 三选一升级、投石机升级
- 野人岛（探索 / 进攻）
- 深海：偶遇沉船、打野人船（野人船）
- 区服聊天 + 世界频道（快捷短语 + 表情，不开自由打字）
- 科研废墟活动、月活动 7 天卡
- 首版之外的其他岛屿模板（若首版只上 4 种）

**v2.0（不变，见 v5.5 11.2）**：远洋、PVP、交易、结盟、AI 玩家、30 天保护卡、内购。
