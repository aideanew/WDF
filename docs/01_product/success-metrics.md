# 成功指标（内部目标值）

| 指标 | 初始目标 |
|---|---|
| 30 秒内学会出钩 | ≥70% 试玩者 |
| 教学后首钩命中率 | ≥45% |
| 前 10 钩成功率 | 40–60% |
| 次日留存 | 先争取 ≥25% |
| 七日留存 | 先争取 ≥8% |
| 单次有效游玩 | 3–8 分钟 |
指标按平台、来源、版本分开看；几百到一千名真实新玩家后再下结论。
