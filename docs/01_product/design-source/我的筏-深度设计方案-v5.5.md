## 一、核心玩法与操作

### 1.1 定位与核心要求
- 【已定】游戏名《我的筏不可能这么大》，简称“我的筏”。
- 【已定】借《疯狂水世界》的题材热度切入，用差异化的核心操作（亲手出钩）区别于挂机拾荒。
- 【已定】目标风格：生存、资源。除了打捞木板、衣服，还要捕鱼（玩家控制）；资源有限；要种菜养活自己，还要战斗、发展。
- 【已定】四条核心要求：
  1. 简单，容易上手，打着打着就会了；
  2. 核心循环，能让玩家长时间玩；
  3. 低配，适用于手机端、小程序端等轻量设备；
  4. 含有已被市场测试证明的爆款配方元素。
- 【已定】参考游戏：《Smash Fest!》《Coin Master》、海克斯大乱斗、羊了个羊、《Raft》。
- 【已定】你看重的点：省份（地域）排名；低网配置，断网也能玩；上头；有独特的创意。
- 【已定】（10-23 09:15）账号：微信、抖音、以后的 APP 都只是入口，共用一套前后端逻辑。没绑定前各自独立、不互通；玩家把微信和抖音绑定后，视为同一个账号（同一份存档、同一个排名身份）。【建议】服务器用内部玩家 ID，下面挂各平台身份；绑定时两边都有进度，让玩家选保留哪一份。
- 【已定】不应该越做越复杂；不做维修。

### 1.2 核心操作：长按蓄力出钩
- 【已定】长按控制力度，角色挥绳打捞；能否捞到取决于力度控制的精准度（像《Raft》）。
- 【已定】力度刻度为**弧形**，力度不同颜色不同：**蓝 → 绿 → 红**。
- 【已定】长按时力度一直循环：0 → 最高 → 0，往复，往返一趟约 **1.2 秒**。
- 【已定】出钩**不限次数**。限制来自：每钩的回收时间（越远越久）、承重（细绳 / 粗绳 / 钢缆三档）、货舱（甲板满了要处理）。**没有体力限制。**
- 【已定】同一套“长按蓄力”手感复用到：打捞、钓鱼、投掷烟雾罐 / 火罐、控制水下装置下潜位置、开锁施力、每日一海出钩。
- 【已定】（10-22 16:54 用户选 1）新手引导：前 10 钩显示虚线落点；第 11–30 钩只显示落点光圈；之后不显示，靠手感。
- 【已定】（10-22 16:54）**不做擦钩**：严格判定，差一点就是没捞到。
- 【已定】（10-22 16:54）连钩：一钩带到一串漂浮物只给屏幕震动，不给加成。
- 【已定】（10-22 16:54 用户选 1）备选方案：如果长按手感测试不好，改成“绳钩摆到合适位置时松手”的时机判断，其他系统不变。

### 1.3 核心循环
【已定】（各层内容来自已定规则；表格本身是整理）

| 层级 | 时长 | 玩家在做什么 | 驱动力 |
|---|---|---|---|
| 秒级 | 2–3 秒 | 一钩 / 一竿 / 一次开锁 | 命中爽感、稀有物闪光、捞到箱子 |
| 小时级 | 真实时间每 6 小时一波潮（每波 10 分钟） | 平时零星打捞；潮来时高峰打捞；潮间整理、建造、派工、钓鱼、派潜水员、甲板开箱 | 承载快满时的取舍 |
| 天级 | 每次上线 | 回岛入库、扩筏、建设岛屿基地、派员工、去深海 / 远洋做五项玩法、卖给商人、每日一海（20:00–21:00） | 筏和岛肉眼变大、员工帮你干活 |
| 周级 | 每周 / 赛季 | 称号每周一更新、赛季榜结算、独家沉船信息每周补货、远洋 PVP（第二版） | 地域荣誉、称号加成、收藏、社交 |

### 1.4 成长与经验
- 【已定】初始只有一个小木筏和一根绳子，从打捞基础资源开始建基地。
- 【已定】边搭木板边扩大：**木筏 → 快艇 → 邮轮**，需要的资源越来越多。
- 【已定】经验来自打捞 + 建设（例如每升级解锁一件新装备涨经验）。玩家**达到一定等级才能驶出浅海**。
- 【已定】原料→基础材料→基础工具只要玩家等级；高级、精密、仪器类还要图纸 + 对应员工（见 5.4、第十三章）。
- 【建议】成长要解锁新能力和新玩法，而不只是更多资源、更高数值。
- 【建议】每次扩建镜头自动拉远一下，关键节点生成“第 1 天 vs 今天”对比图用于分享。

### 1.5 驾驶与海图
- 【已定】船可以驾驶，只保留基本控制。
- 【已定】有海图，可以挂机导航让船员自己开，显示预计消耗和用时。
- 【已定】探索解锁海图区域，未探索部分显示迷雾。
- 【已定】有发动机才能替代人划船；没有发动机时用桨划。发动机烧燃油、要装舵；筏越大要的发动机越多，不够就变慢（见第六章、第十三章）。
- 【已定】（10-22 16:54）只常驻一个切换按钮，用图标不用文字：在甲板时是“去驾驶”；进了驾驶或房间就变成“回甲板”。
- 【已定】（10-22 16:54）扩建流程：先选建什么，再选放哪；房间建好后点一下就能进去。扩建时镜头拉远，首版不做“第 1 天 vs 今天”分享图。

## 二、海域：浅海 / 深海 / 远洋与潮汐

### 2.1 世界结构
- 【已定】世界没有大陆，只有岛屿。筏一直在海上漂，没有“出航、回筏”这回事。
- 【已定】三圈海域（正式名称）：

| 海域 | 位置 | 漂浮物 | 岛与野人 | 安全性 | 主要玩法 |
|---|---|---|---|---|---|
| **浅海** | 出生点，最内圈 | 多（潮来更多） | 无 | 新手保护：只有玩家自己一个人，安全，发育好了再出去 | 打捞、潮汐、钓鱼、扩筏 |
| **深海** | 中间圈 | 少很多 | 有岛、有野人 | 筏不会被攻击；只能掠夺野人的船 / 木筏 | 五项玩法（见 2.3）、占岛 |
| **远洋** | 最外圈 | 没有 | — | 第二版起可发生船对船掠夺 | 五项玩法；船对船 PVP（第二版） |

- 【已定】**深海地图 800×800（km）**；野人按 100 km/小时航行（见 7.1）。
- 【已定】（10-22 16:54，17:59 确认面积）浅海尺寸原型期按航行时间调；远洋将来最好无限大，首版先按 10 个深海的总面积做，约 2500×2500 km。
- 【已定·Hark代定】（10-23 10:45）**玩家航速**由帆 / 引擎等装备决定，数值放 game-data（【可调】）；初始值按“基础筏横穿深海一边（800 km）约 30 分钟实时”反推。~~（原稿未定航速）~~
- 【已定】驶出浅海的条件：玩家等级达到要求。
- 【已定】公平性：相近时间加入的玩家分到同一片海域 / 同一区服，游戏玩法暂时不允许跨海域、不支持跨区服（世界频道例外，见 9.4）。
- 【已定】（10-23 10:23，拍板5）**要做区服**；什么时候开新区由**管理员控制**；新玩家进入**当前开放的新区**。
- 【已定】（10-22 16:54）深海、远洋的危险（天气、暗礁、生物）首版不做，第二版再加。

### 2.2 潮汐（浅海）
- 【已定】浅海按**真实时间每 6 小时**来一波潮，每波持续 **10 分钟**：
  - 没有潮时，漂浮物零星，慢慢漂过来；
  - 潮来时，漂浮物多，流速变快，还会有稀有道具。
- 【已定】玩家不在线时这波潮就错过了；错过多了也**没有惩罚**；错过会留下少量“潮痕”漂浮物。
- 【已定】**不用**微信订阅消息提醒；在“**活动**”栏点开就能看到每波潮的开始和结束时间。

### 2.3 深海与远洋的五项玩法
【已定】深海和远洋**都支持**以下五项，**首版都要做**：
1. 抢野人、攻击野人（深海只能掠夺野人的船 / 木筏）；
2. 采集石油；
3. 沉船探索（派员工潜水 / 水下装置打捞）；
4. 探索无人小岛、关键区域，获取珍稀道具；
5. 钓鱼 / 捕鱼。

> 【已定】提醒：五项全做 + 商人 + 开锁 + 每日一海 + 称号 + 9 兵种，一个月首版工期会很紧，排期时**砍深度不砍种类**。

## 三、打捞、钓鱼、沉船、石油、探索与箱子

### 3.1 打捞
- 【已定】漂浮物（按物品总表）：漂流木、布、塑料、废铁、废铜、种子、**铁钉和少量铁锭**（浅海无岛阶段的金属来源）、稀有道具、**箱子**（见 3.6）。原话里的“木板、衣服”分别对应漂流木（加工成木板 / 木棍）和布；细绳、铁钉是加工品（见第十三章）。
- 【已定】**开锁工具不在水面直接漂**，只从箱子、沉船、商人得到（见 8.4）。
- 【已定】打捞装备升级路线：**单个铁钩 → 更快更远 → 多爪钩（一次多个铁钩）→ 绞盘 → 短距离打捞网 → 更快更远 → 打捞网范围升级 → 自动打捞装置**。
- 【已定】配方：抓钩 = 铁钉 + 细绳；多爪钩 = 抓钩 + 铁锭 ×2；打捞网 = 粗绳 ×5 + 帆布；绞盘 = 铁锭 ×4 + 齿轮 ×2（需要铁）；**自动打捞装置（水上）= 绞盘 + 钢缆 + 打捞网 + 发动机**（见第十三章）。
- 【已定】绳子也可升级，可打捞的东西越来越重；钩的绳子决定承重：细绳 / 粗绳 / 钢缆三档。
- 【已定】后续可建更高级的打捞工具，甚至水下打捞工具：**自动捕捞装置（水下）= 绞盘 + 钢缆 + 捕捞网 + 发动机**；水下探寻装置 = 木板 + 钢缆 + 潜水服 + 水下探照灯。
- 【已定】**自动打捞装置要耗电**，并受货舱容量限制，满了就停（电力定位见第六章）。
- 【已定】（10-22 16:54）发动机只是自动打捞装置配方里的零件；装置运转只耗电，不烧油。
- 【已定】（10-22 16:54）自动打捞只慢慢捞普通小件；稀有物和重物要手动出钩；离线自动收益不计榜。
- 【已定】（10-22 16:54）不做功能型钩子（磁力钩等）。

### 3.2 钓鱼
- 【已定】钓鱼复用出钩手感，用途：供粮、喂电鳗（发电）。鱼竿 = 木棍 + 细绳。
- 【已定】鱼种：鱼、**电鳗**、**灯笼鱼**（灯笼鱼可做诱鱼灯、水下探照灯）。
- 【已定】钓鱼可升级成**网拖**（捕捞网 = 打捞网 + 铁锭 ×2）；另有捕鱼笼（木棍 ×4 + 细绳 ×2，取代原“捕鳗笼”）。
- 【已定】玩家自己永远能钓鱼自救，不会进入死局（沿用“永不死局”原则）。

### 3.3 沉船
**获取沉船信息**
- 【已定】在商人处购买沉船信息（坐标）解锁，然后自己开船去打捞。
- 【已定】沉船信息分三级~~，按**本区服**计量~~，暂不跨区服（份数归属见 10-23 10:45 条）：

| 等级 | 本区服份数 | 有效期 | 说明 |
|---|---|---|---|
| 普通 | 100 份 | 1 天 | 按玩家各自结算 |
| 高级 | 10 份 | 3 天 | 按玩家各自结算 |
| 独家 | 3 份 | 7 天 | 代表远洋中的不同位置；本区服卖了就没有了，只对买家显示；**每周补 3 份** |

- 【已定·Hark代定】（10-23 10:45）份数**每个玩家各刷各的、互不抢**；~~“本区服份数”“本区服卖了就没有了”~~ 作废，表头“本区服份数”读作“每人份数”。

## 四、筏与岛

### 4.1 筏 = 移动采集船
- 【已定】筏有承载上限：建筑和货物共同占用；初期不能无限打捞。扩浮台提升上限，筏变大（筏块 = 木板 ×2 + 塑料；货舱 = 木板 ×6 + 铁钉 ×2）。
- 【已定】（10-22 16:54，4-1）承载做成直观系统，不模拟真实浮力和吃水。
- 【已定】（10-22 23:02）**船体建设核心规则：整船浮力 ≥ 整船总重量**。船的浮力 = 船上全部船体材料的容量之和；材料本身也占容量。小游戏，不做复杂结构。
- 【已定】（10-22 23:02）**房间统一大小**，玩家随便怎么建；搭好第一层房间，就能像**堆积木**一样往上加盖，层数玩家自定（取代 16:54 Hark 建议里“房间尺寸、楼层承载”待选项）。
- 【已定】（10-22 23:03）**加盖要先有研究室**：没有研究室（科研部）时只能在第一层扩建，建不了第二层房间；有了研究室，由研究员研究“结构”，船才能“增高”（与 5.3“船体建设由研究员决定”一致）。
- 【建议】每种船体材料标一个“容量（浮力）”数值，每件建筑 / 货物 / 员工标一个“重量”；建造或装货时实时显示 浮力 / 重量，超了就不能再建或再装。具体数值配表时定。
- 【已定】筏在浅海、深海暂时不会受到攻击；野人只打岛，不打筏。远洋第二版起可能被其他玩家船对船掠夺（见 8.1）。

- 【已定】筏上设施设想（用户原话）：科研室（发电机、太阳能、电池、灯等）、阳光房（种菜）、厨房（做饭、冰箱）；船上有装水下装置的固定机位。

- 【已定】岛屿模型多种多样；可以和岛屿互动。
- 【已定】玩家在基地派遣留守队伍；有了无线电设备后可以远程管理基地。
- 【已定】岛屿分两区：**塔防阵地**和**建设区**。过了阵地才能进大门，进了大门才到建设区；建筑不占塔防阵地的格子。

### 5.4 图纸与制作
- 【已定】**门槛**：原料 → 基础材料 → 基础工具 **只要等级，不要图纸**；高级、精密、仪器 **要图纸 + 玩家等级 + 对应员工**。
- 【已定】中大型关键道具和设备需要图纸；图纸可以通过活动领取；商人卖基础图纸、偶尔卖高级图纸；珍稀图纸只能自己探索获得。图纸不可打造。
- 【已定】需要铸造 / 打造的高级物品要同时满足：**玩家等级到、图纸解锁、制作者（工匠）等级到**。不能制作的显示**灰色**，点击显示原材料和原因，例如：图纸 √ / 玩家等级 ≥20 √ / 铁匠等级 ≥5 ×。
- 【已定】配方标准：**精炼配方极短，一眼就懂**（最多 3 种材料，用户指定的组合除外）。
- 【已定】**自动合成**：缺中间材料时，配方旁出现“自动合成”按钮，按原料一路自动做完；缺设施或员工的环节按钮变灰并写明原因。
- 【已定】**研究台**：第一次捞到新原料放上去研究，解锁相关基础配方。
- 【已定】**原型制**：基础工具第一次在岛上设施旁做出来后，筏上工作台也能做。
- 【已定】**工作台附件**（锯台、砧台）升级，高级配方要附件齐全。
- 【已定】**兵器护甲不做物品**，造兵时算在兵种升级里消耗材料；弓箭和弩的箭都无限；弓弩车自带弩，弩不用造。
- 【已定】很多东西不能打造：开锁工具、发电机、发动机、图纸、种子、宝石、古董、保护卡、加速卡、沉船信息。
- 【已定】（10-22 16:54，5-9）图纸解锁技术，专业员工提供岗位能力，两者分开。除完整图纸外，还会出现**不知名的图纸、地图残片、未知材料**，都要研究员研究。
- 【已定】（10-22 16:54，5-10）打 × 的那行可直接点去对应建筑。
- 【已定】设施—员工按上面 7 岗位表归属（5-8）；【待定】各物品要几级。

### 5.5 品质、品阶与物品等级
- 【已定】同一物品分品质，不同品质各占一格；木板等基础材料不分品质。
- 【已定】物品有等级，例：金锁只能用最高级的开锁工具（高级开锁工具）。

## 六、电力
- 【已定】**电力定位：和燃油一样，是高级设备的必要元素。**（取代 v5.3 的“电力只作解锁条件、不做核心”）
- 【已定】自动打捞装置等高级设备要持续耗电（见 3.1）；电动海水过滤器、冰箱耗电。
- 【已定】发电方式：
  - **太阳能**：免费、慢速保底（太阳能板 = 电线 ×2 + 塑料 ×4，高级）；
  - **电鳗发电机**（鳗鱼发电机）= **电鳗 ×2 + 发电机**（仪器），要喂鱼（接上钓鱼）；
  - **石油发电**：石油只在深海（及远洋）开采，出力大但会消耗。
- 【已定】**发电机、发动机不能自己生产**（不可打造），在岛上装到筏上。【已定】（10-22 16:54，6-1）来源见 9.2。
- 【已定】燃油 = 石油 ×2（炼油炉）。燃料不写进配方：窑、熔炉烧木炭；高炉、炼油炉、发动机烧燃油。
- 【已定】发动机烧燃油、要装舵；筏越大要的发动机越多，不够就变慢；有发动机才能替代人划船。
- 【已定】（10-22 16:54，6-3，取代“简易版烧燃料”）净水分三种：**简易海水过滤器不耗燃料**（慢）；**高级过滤器**烧燃料，木炭燃烧效率更高更久；**电力净水器**耗电。高级过滤器配方待补。
- 【已定】（10-22 16:54，6-2）灯耗电，提升夜间产出或幸福感；例外：**灯笼鱼灯不耗电，但要喂吃的**。员工和其他生物的消耗自动结算。
- 【已定】（10-22 16:54，6-2）员工会说话：玩家可进厨房和厨师交流（如“今晚加班”）；食材不够时厨师会主动找玩家；其他员工饿了会说“好饿呀”，玩家在画面上能看到员工的吐槽。
- 【已定】（10-22 16:54，6-4）出力起步 太阳能 : 电鳗 : 石油 = 1 : 3 : 10，原型再调；各设备耗电待定。

## 七、野人袭击与塔防

### 7.1 野人
- 【已定】野人部落会时不时袭击玩家基地，保持新鲜度。
- 【已定】袭击频率由**野人窝点**和**路程**决定；**没有预警**。
- 【已定】野人按 **100 km/小时**航行；深海地图 800×800 km；**袭击间隔 = 窝点到岛的路程时间**（最远对角约 1131 km ≈ 11.3 小时）。
- 【已定】（10-22 16:54，7-2）野人窝点**每周刷新一次**，随机；一个玩家基地周围 **1–2 个**；一般**同等级或低等级**，规模随玩家岛等级增长，但不出现大规模高等级野人针对玩家。
- 【已定】野人**只攻击基地（岛），不打筏**；浅海没有野人（新手保护）。
- 【已定】开着保护卡时野人不来打（见 4.4）。
- 【已定】玩家不在线野人也会来，按塔防**自动结算**，上线可看**回放**。防守方只有在线时才能扔道具（烟雾罐、火罐）。
- 【已定】（10-23 10:23，拍板8）塔防按**迷宫塔防 + 回放**做（7.2 规则不变）。**保底**：第 3 周末还不稳定，就临时改成**离线文字结算、先不做回放**，稳定后再补回来。保底只影响“有没有回放画面”，不改攻防规则。
- 【已定】野人**不会开锁**。上锁的大仓库挡得住野人。
- 【已定】野人进门后会掠夺掉大部分基础物资：主抢食物（农田、厨房），也抢未上锁的箱子、露天木板等，并造成守军战损。
- 【已定】（10-22 16:54，7-1）野人和第二版的玩家 PVP 共用一套战斗框架（塔防规则已定为共用）。
- 【已定】**第二版**：让 AI 扮演并操作一个**虚拟玩家**、操作**野人**，**每 2 小时**来操作一次。

### 7.2 塔防规则（野人与 PVP 共用）
- 【已定】攻防就是“**玩家可以自定义地形的塔防策略**”：同一套塔防规则，地形由玩家自己修；修出窄路就是火力走廊，没修好就是开阔地硬拼，不再是两套系统。
- 【已定】玩家可以升高地形（每格石头 ×2，用铲子），敌人过不去，只能走留出的那条路，形成“塔防领域”。
- 【已定】岛屿一般有几个登陆口岸（区别于常规塔防）。
- 【已定】进攻方要配置进攻人员，包含每个人的顺序。进攻队伍**自动规划最短路线直取大门**，进门即胜利；胜利后进入建设区搜刮（PVP 有开锁环节，第二版）。
- 【已定】不做拆路障。
- 【已定】基地要有**军营**（兵营 = 木板 ×20 + 砖 ×10）和**装备营**，用来研发箭塔、投石机等。
