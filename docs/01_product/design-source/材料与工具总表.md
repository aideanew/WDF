# 物品、材料与工具总表（定稿 2026-10-21 17:18）
本文件是物品体系唯一总账，已合并 16:27～17:18 的讨论，只保留现行规则；旧草案已删除。后续新增直接改这里。
标准：配方极短，一眼就懂（最多 3 种材料，用户指定的组合除外）。
门槛：原料→基础材料→基础工具 只要等级；高级/精密/仪器 要图纸+等级+对应员工。熔炉、窑只在岛上。兵器护甲算兵种升级，箭无限。
**自动合成（用户 17:10 定）**：缺中间材料时，配方旁出现“自动合成”按钮，按原料一路自动做完，不用一个个合。缺设施或员工的环节按钮变灰并写明原因。
燃料不写进配方：窑、熔炉烧木炭，高炉、炼油炉、发动机烧燃油。

## 十二、物品体系已定规则
- 基础物资是打造高级工具的材料；很多东西不能打造（如开锁工具、发电机、发动机）。
- 物品分可打造 / 不可打造；可打造按 原料→基础材料→基础工具→高级→精密→仪器 分层。
- 原料→基础材料→基础工具 只要等级；高级、精密、仪器要图纸+等级+对应员工；建设施本身不要工匠。
- 熔炉、窑只能放岛上；木筏只处理木、布、绳。大件在岛上做好再装到筏上。
- 研究台：第一次捞到新原料放上去研究，解锁相关基础配方。
- 原型制：基础工具第一次在岛上设施旁做出来后，筏上工作台也能做。
- 工作台加附件（锯台、砧台）升级，高级配方要附件齐全。
- 发动机烧燃油、要装舵；筏越大要的发动机越多，不够就变慢；有发动机才能替代人划船。
- ~~海水过滤器两级：简易版烧燃料，电动版耗电。~~ 【修正 10-23】以 10-22 新定为准：简易过滤器不耗燃料、高级过滤器烧燃料、电动耗电（见本表末尾）。
- 金属（废铁、废铜、锭）用加速卡、一键入库无效，必须开船运回。
- 兵器护甲不做物品，造兵时算在兵种升级里；弓箭和弩的箭无限；弓弩车自带弩。
- 缺中间材料时提供“自动合成”按钮。
- 浅海无岛阶段，铁钉和少量铁锭要能从漂浮物、箱子捞到。
